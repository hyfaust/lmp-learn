## 背景知识

### 压力的微观含义

在宏观世界中，压力是"单位面积上的力"。但在微观的分子动力学模拟中，压力来自两个方面：

1. **动能贡献（理想气体项）**：原子在运动中不断碰撞容器壁（或模拟盒子的边界），产生压力。这部分与温度直接相关，公式为 $Nk_BT / V$，其中 $N$ 是原子数，$k_B$ 是玻尔兹曼常数，$T$ 是温度，$V$ 是体积。
2. **势能贡献（维里项）**：原子之间的相互作用力也会对压力有贡献。当原子之间存在吸引力时，会"拉住"容器壁，降低压力；当存在排斥力时，则会"推"容器壁，增加压力。

**维里定理（Virial Theorem）** 将这两部分统一起来：

$$P = \frac{Nk_BT + W}{V}$$

其中 $W$ 是**维里（Virial）**，定义为：

$$W = \frac{1}{3} \sum_{i} \mathbf{r}_i \cdot \mathbf{f}_i$$

这里 $\mathbf{r}_i$ 是原子 $i$ 的位置矢量，$\mathbf{f}_i$ 是原子 $i$ 受到的合力。直观理解：维里项衡量了原子间力对压力的净贡献。

**压力是张量**：严格来说，压力有方向性（pxx、pyy、pzz、pxy、pxz、pyz 六个分量）。但在各向同性系统（如均匀液体）中，三个对角分量在统计平均上相等，因此常用一个标量压力 $P = (p_{xx} + p_{yy} + p_{zz}) / 3$ 来表示。

**压力涨落大**：与温度相比，压力的涨落要大得多。对于一个包含 $N$ 个粒子的系统：

- 温度的相对涨落约为 $\sim 1/\sqrt{N}$
- 压力的相对涨落约为 $\sim 1/\sqrt{N}$，但压力的**绝对涨落**远大于温度

这就是为什么压力控制需要更长的弛豫时间（更大的 P_damp），也是为什么 NPT 模拟比 NVT 模拟需要更长的平衡时间。

### 为什么需要 NPT 系综？

在前面的项目中，我们学习了 NVT 系综（固定粒子数 N、体积 V、温度 T）。但 NVT 系综有一个重要限制：**密度是固定的**。如果初始设置的密度不是该温度下的平衡密度，系统就无法自动调整。

NPT 系综（固定粒子数 N、压力 P、温度 T）解决了这个问题：

1. **模拟真实实验条件**：绝大多数实验在恒温恒压条件下进行（例如，在大气压下加热样品）。NPT 系综最接近实验条件。
2. **自动确定平衡密度**：在给定温度和压力下，系统会自动调整盒子体积，直到内部压力与目标压力一致。此时的密度就是该温度压力下的**平衡密度**。
3. **模拟相变**：通过改变温度或压力，可以观察熔化、凝固、结晶等相变过程。例如，升温使固体熔化时，密度会发生突变。
4. **研究压力对材料性质的影响**：系统地改变目标压力，观察材料结构、力学性质的变化。
5. **对比 NVT 的局限性**：在 NVT 下，如果密度设置不当，系统可能处于亚稳态甚至非物理状态。NPT 能自动找到正确的平衡状态。

| 系综 | 固定量 | 可变量 | 典型应用 |
|------|--------|--------|----------|
| NVE  | N, V, E | T, P | 验证能量守恒 |
| NVT  | N, V, T | P, ρ | 固定密度下的温度控制 |
| NPT  | N, P, T | V, ρ | 确定平衡密度，模拟相变 |

### Nosé-Hoover 恒压器

LAMMPS 中的 NPT 系综使用 Nosé-Hoover 恒压器（barostat）来控制压力。其核心思想非常巧妙：

**引入一个"活塞"自由度**：想象在模拟盒子外有一个虚拟的"活塞"，它与盒子中的原子耦合。当内部压力高于目标压力时，活塞向外移动（盒子膨胀）；当内部压力低于目标压力时，活塞向内移动（盒子收缩）。

**具体实现原理**：

1. 在拉格朗日量中引入一个与体积相关的额外自由度 $s$（类似于恒温器中的热浴变量）
2. 盒子的实时体积为 $V = V_0 \cdot s^3$（三维情况），其中 $V_0$ 是参考体积
3. 通过运动方程自洽地演化 $s$，使得平均压力趋近于目标值

**与 Nosé-Hoover 恒温器的类比**：

| 恒温器 | 恒压器 |
|--------|--------|
| 引入热浴变量 $s_T$ | 引入活塞变量 $s_P$ |
| 控制原子速度的缩放 | 控制盒子尺寸的缩放 |
| T_damp 控制温度弛豫速度 | P_damp 控制压力弛豫速度 |
| 原理：调节动能 → 调节温度 | 原理：调节体积 → 调节压力 |

**在 LAMMPS 中的命令格式**：

```
fix ID group-ID npt temp Tstart Tstop Tdamp keyword args ... press Pstart Pstop Pdamp
```

其中：
- `Tstart` / `Tstop`：起始和终止温度（可以做升温/降温过程）
- `Tdamp`：温度弛豫时间参数
- `Pstart` / `Pstop`：起始和终止压力
- `Pdamp`：压力弛豫时间参数

### 各向同性 vs 各向异性压力耦合

压力控制有两种主要模式，选择哪种取决于模拟的物理场景：

**各向同性（iso）**：

```
┌──────────┐          ┌────────┐
│          │          │        │
│          │    →     │        │
│          │          │        │
└──────────┘          └────────┘
```

- 三个方向（x、y、z）**等比例缩放**
- 盒子始终保持立方体（或保持初始的长宽比）
- 适用于：**液体**、气体、非晶态材料、不需要关心方向差异的系统
- 这是最常用、最稳定的压力耦合方式

**各向异性（aniso）**：

```
┌──────────┐          ┌────────────┐
│          │          │            │
│          │    →     │  ┌──────┐  │
│          │          │  └──────┘  │
└──────────┘          └────────────┘
```

- 三个方向**独立缩放**，每个方向有自己的目标压力
- 盒子可以从立方体变成长方体
- 适用于：**晶体结构**、各向异性材料、需要确定非立方晶格参数的系统
- 可以对不同方向施加不同的目标压力（模拟非均匀应力）

**三斜盒子（tri）**：

- 在 aniso 基础上，还允许盒子的三个角度（α、β、γ）变化
- 适用于：三斜晶系的晶体、极端条件下的材料模拟
- 初学者一般不需要使用

**选择建议**：

| 系统类型 | 推荐耦合方式 |
|----------|-------------|
| LJ 液体 | iso |
| 水溶液 | iso |
| fcc/bcc 金属晶体 | iso 或 aniso |
| 非立方晶体（hcp、四方等） | aniso |
| 层状材料（石墨、MoS₂） | aniso |
| 拉伸/压缩模拟 | aniso（不同方向不同压力） |

### P_damp 参数选择

P_damp 是控制压力弛豫速度的关键参数，选择不当会导致模拟问题：

**P_damp 太小（弛豫太快）**：
- 体积会发生**剧烈振荡**（过冲 → 欠冲 → 过冲...）
- 可能导致模拟不稳定甚至崩溃
- 类比：用力过猛地踩油门和刹车

**P_damp 太大（弛豫太慢）**：
- 压力收敛极慢，需要非常长的模拟时间
- 在有限的模拟时间内可能无法达到平衡密度
- 类比：用极轻的力度踩油门，几乎看不到速度变化

**经验值**：

| 单位制 | P_damp 推荐范围 | 说明 |
|--------|-----------------|------|
| LJ 单位 | 1.0 ~ 10.0 | 本项目使用 5.0 |
| metal 单位（GPa） | 1000 ~ 10000 个时间步对应的时间 | 例如 dt=1fs，P_damp=1000~10000 fs |
| real 单位（atm） | 1000 ~ 10000 个时间步对应的时间 | 例如 dt=1fs，P_damp=1000~10000 fs |

**经验法则**：P_damp 应该取 $1000 \times dt$ 到 $10000 \times dt$ 之间。对于本项目（dt = 0.005），P_damp 取 5.0 到 50.0 是合理的。

**与 T_damp 的对比**：
- 温度弛豫通常比压力弛豫快（温度涨落小）
- T_damp 一般取 100×dt
- P_damp 一般取 1000×dt，比 T_damp 大约一个数量级
- 本项目中：T_damp = 0.5，P_damp = 5.0（恰好差 10 倍）

### 密度自洽

NPT 模拟最迷人的特性之一就是**密度自洽**：无论初始密度设置为多少，经过足够长时间的 NPT 模拟后，系统都会自动收敛到该温度和压力下的平衡密度。

**密度计算**：

$$\rho = \frac{N}{V}$$

在 LAMMPS 的 LJ 单位制中，`density` 关键字直接给出约化密度 $\rho^* = N\sigma^3 / V$。

**密度收敛过程**：

1. **初始阶段**（前几千步）：密度快速变化，偏离初始值
2. **中间阶段**：密度围绕平衡值振荡，振幅逐渐减小
3. **平衡阶段**：密度在平衡值附近小幅度涨落

**LJ 液体在 T*=1.0、P*=0.5 下的预期密度**：

对于标准的 LJ 系统，在 T*=1.0、P*=0.5 条件下，平衡密度约为 $\rho^* \approx 0.28$。这比初始密度 0.864 低得多——系统会自动膨胀以降低内部压力。密度变化幅度取决于初始密度与平衡密度之间的差距：差距越大，密度变化越明显，这恰好是展示 NPT 密度自洽的绝佳案例。注意：由于我们使用了截断势（而非完整的 LJ 势），且没有长程色散校正，实际平衡密度可能与文献中的 LJ 状态方程（EOS）预测值略有差异。

**密度收敛的时间尺度**：
- 快弛豫模式（体积的快速调整）：几千步
- 慢弛豫模式（局部结构重组）：几万步
- 对于 LJ 液体，一般 10000~50000 步可以达到很好的平衡
- 对于高粘度系统（如聚合物、玻璃），可能需要更长时间

## 输入脚本逐行解析

### in.npt — 各向同性 NPT 模拟

脚本分为以下几个阶段：

**阶段一：初始化与体系创建（第 1~40 行）**

```lammps
units           lj
atom_style      atomic
region          mybox block 0 10 0 10 0 10
create_box      1 mybox
lattice         fcc 0.8442
create_atoms    1 box
mass            1 1.0
pair_style      lj/cut 2.5
pair_coeff      1 1 1.0 1.0 1.0
```

与前面项目完全相同：创建 LJ 液体系统，密度 0.8442，截断半径 2.5σ。

**阶段二：初始速度（第 42~45 行）**

```lammps
velocity        all create 1.0 12345 loop geom
```

初始温度设为 T*=1.0，与 NPT 目标温度一致，减少不必要的温度弛豫。

**阶段三：NVT 预平衡（第 50~70 行）**

```lammps
fix             nvt_fix all nvt temp 1.0 1.0 0.5
run             5000
unfix           nvt_fix
```

在固定体积下先让温度稳定。这一步的作用：
- 让系统从晶格初态进入液态结构
- 稳定温度，避免 NPT 阶段初期体积剧烈变化
- 5000 步（25τ）足够让 LJ 液体基本达到温度平衡

**阶段四：NPT 生产模拟（第 75~100 行）**

```lammps
fix             1 all npt temp 1.0 1.0 0.5 iso 0.5 0.5 5.0
reset_timestep  0
run             50000
```

这是核心部分。逐个参数解释：

| 参数 | 值 | 含义 |
|------|-----|------|
| `temp` | 关键字 | 接下来是温度参数 |
| `1.0` | Tstart | 起始温度 T*=1.0 |
| `1.0` | Tstop | 终止温度 T*=1.0（恒温） |
| `0.5` | T_damp | 温度弛豫时间 = 0.5τ |
| `iso` | 关键字 | 各向同性压力耦合 |
| `0.5` | Pstart | 起始压力 P*=0.5 |
| `0.5` | Pstop | 终止压力 P*=0.5（恒压） |
| `5.0` | P_damp | 压力弛豫时间 = 5.0τ |

**阶段五：统计分析（第 100~120 行）**

使用 `fix ave/time` 对后 10000 步进行时间平均，输出平均密度、温度、压力和盒子尺寸。

### in.npt_aniso — 各向异性 NPT 模拟

与 `in.npt` 的唯一核心区别在于：

```lammps
fix             1 all npt temp 1.0 1.0 0.5 aniso 0.5 0.5 5.0
```

将 `iso` 改为 `aniso`，意味着三个方向独立耦合。

额外输出了：
- `box_dimensions.dat`：三个方向盒子尺寸随时间的变化
- `pressure_components.dat`：压力张量分量（pxx、pyy、pzz）

对于各向同性液体，三个方向的盒子尺寸和压力分量在统计上应该相等，但瞬时涨落不同。如果你发现三个方向的平均值有明显差异，说明平衡时间还不够长。

## 预期输出

### in.npt 的预期行为

运行 `lmp -in in.npt` 时，你应该看到类似以下的热力学输出：

**NVT 阶段**（前 5000 步）：
```
Step Temp Press Volume Lx Ly Lz Density
   0    1.0xxx   xxxxx    1000  10.0  10.0  10.0   0.8640
 100    0.9xx    xxxxx    1000  10.0  10.0  10.0   0.8640
 ...
5000    1.0xx    xxxxx    1000  10.0  10.0  10.0   0.8640
```

注意：NVT 阶段体积和密度不变（固定体积），只有温度在弛豫。LAMMPS 在 `region 0 10` 内创建了 864 个原子，初始密度为 864/1000 = 0.864。

**NPT 阶段**（5000 步后，重置为 0）：
```
Step Temp Press Volume Lx Ly Lz Density
   0    1.0xx   xxxxx    1000  10.0  10.0  10.0   0.8640
 1000  1.0xx   xxxxx    1766  12.1  12.1  12.1   0.4893
 ...
10000  1.0xx   xxxxx    ~2800 ~14.1 ~14.1 ~14.1   ~0.31
 ...
50000  1.0xx   xxxxx    ~3130 ~14.6 ~14.6 ~14.6   ~0.28
```

**重要：密度自洽的精彩演示！** 初始密度为 0.864，但在目标压力 P*=0.5 条件下，平衡密度约为 0.28。系统自动膨胀以降低内部压力，最终达到目标压力下的平衡密度。这正是 NPT 系综的核心能力——**无论初始密度如何，系统都会自动找到平衡密度**。

**关键观察**：
- **温度**：围绕 T*=1.0 小幅度涨落，基本稳定
- **压力**：围绕 P*=0.5 较大幅度涨落（这是正常的！压力涨落比温度大得多）
- **体积/盒子尺寸**：初期快速变化，然后趋于稳定
- **密度**：从初始值 0.864 **显著变化**到平衡值约 0.28，展示了密度自洽现象

> **为什么密度从 0.864 变到 0.28？** 在 LJ 约化单位下，P*=0.5 对应的平衡密度约为 0.28（T*=1.0）。初始密度 0.864 远高于此值，对应更高的内部压力。系统通过膨胀降低压力，直到内部压力与目标压力 P*=0.5 一致。如果你想看到更高的平衡密度，可以尝试更大的目标压力（如 P*=5.0 或更高），详见练习 1。

### in.npt_aniso 的额外观察

运行 `lmp -in in.npt_aniso` 后，最终输出如下（典型值）：
```
最终盒子尺寸:
  Lx ≈ 16.7
  Ly ≈ 16.5
  Lz ≈ 11.5
最终密度: ~0.27
压力张量分量:
  Pxx ≈ 0.41
  Pyy ≈ 0.41
  Pzz ≈ 0.48
```

**盒子尺寸**：
- 三个方向的盒子尺寸**不相等**！这是各向异性耦合的预期结果
- 即使对于各向同性液体，有限的模拟时间和统计涨落也会导致三个方向产生不同的瞬时平衡尺寸
- 如果运行更长时间，三个方向在统计平均上会趋于一致

**压力张量分量**：
- pxx、pyy、pzz 的值各不相同（0.41、0.41、0.48），都围绕 P*=0.5 涨落
- 它们的瞬时涨落可能很大（压力涨落的典型特征）
- 三个方向的涨落是独立的，不会同步

**对比 iso 与 aniso**：
- iso 下盒子始终保持立方体（lx = ly = lz）
- aniso 下盒子可以变形（lx ≠ ly ≠ lz）
- 对于各向同性液体，两者在长时间平均下应给出相同结果
- 对于晶体或各向异性材料，aniso 能反映真实的方向依赖性

## 练习题

### 练习 1：目标压力对平衡密度的影响

**任务**：分别将目标压力设为 P*=0.1、P*=0.5、P*=1.0、P*=5.0，运行 NPT 模拟，记录每种情况下的平衡密度。

**提示**：修改 `in.npt` 中的：
```lammps
fix 1 all npt temp 1.0 1.0 0.5 iso P_target P_target 5.0
```

**预期结果**：
- P*=0.1：密度很低（约 0.1~0.2），系统大幅膨胀（接近气态）
- P*=0.5：密度约为 0.28（本项目的默认结果）
- P*=1.0：密度约为 0.4~0.5，系统膨胀较小
- P*=5.0：密度较高（可能接近或超过 0.8），系统明显被压缩，接近液态密度

**思考**：绘制密度 vs 压力的曲线，是否能看到非线性关系？

### 练习 2：P_damp 参数的影响

**任务**：将 P_damp 分别设为 0.5、1.0、5.0、20.0、50.0，观察体积涨落和收敛速度的变化。

**预期观察**：
- P_damp = 0.5：体积剧烈振荡，可能不稳定
- P_damp = 5.0：平衡较好（默认值）
- P_damp = 50.0：体积变化缓慢，收敛很慢

**思考**：找到一个 P_damp 值使系统既稳定又收敛快。为什么 P_damp 不能太小？

### 练习 3：LJ 固体的 NPT 模拟

**任务**：在低温高压条件下模拟 LJ 固体，观察晶格参数的确定过程。

**修改参数**：
```lammps
# 改为低温（T*=0.5，低于三相点温度）
velocity        all create 0.5 12345 loop geom
fix             1 all npt temp 0.5 0.5 0.5 iso 5.0 5.0 5.0
```

**预期结果**：
- 系统保持在固态（fcc 晶格）
- 盒子尺寸会调整到使内部压力与 P*=5.0 平衡
- 最终密度比液态时更高
- 可以计算晶格常数：$a = (4/\rho)^{1/3}$（对于 fcc）

### 练习 4：iso vs aniso 对比

**任务**：在相同条件下（T*=0.5，固体），分别运行 `iso` 和 `aniso` 耦合，比较结果。

**预期观察**：
- `iso`：盒子始终是立方体，三个方向尺寸相同
- `aniso`：盒子可能偏离立方体（虽然 fcc 晶体在各向同性压力下应该保持立方体）
- 如果 `aniso` 下盒子明显不是立方体，可能是平衡时间不足或晶格取向问题

**思考**：对于 fcc 晶体，理论上 iso 和 aniso 应该给出相同的结果。为什么？

### 练习 5：NPT 升温过程与熔化

**任务**：使用 NPT 实现升温过程，观察 LJ 固体的熔化现象。

**修改参数**：
```lammps
# 从低温升到高温
fix             1 all npt temp 0.5 2.0 0.5 iso 1.0 1.0 5.0

# 为了看到熔化过程，需要更多步数和更频繁的输出
thermo          50
run             100000
```

**预期观察**：
- 在 T* ≈ 0.7~1.0 范围内（取决于压力），系统会熔化
- 熔化时密度会突变（固 → 液，密度降低）
- Lindemann 参数（原子均方位移）会突增

**思考**：如何判断系统是固态还是液态？可以观察：
1. 密度变化
2. 均方位移（MSD）的变化
3. 径向分布函数 g(r) 的变化（固态有尖锐峰，液态只有近邻峰）
