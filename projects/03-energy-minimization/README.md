## 背景知识

### 什么是能量最小化？

想象你手里拿着一把弹珠，把它们扔到一个凹凸不平的山坡上。弹珠会自动滚到附近的低洼处停下来——这就是能量最小化的直觉。

在原子模拟中：

- **每个原子**就是一颗弹珠
- **势能**（Potential Energy）就是山坡的高度
- **力**（Force）就是山坡的坡度——力指向能量下降最快的方向
- **能量最小化**就是让所有原子同时"滚"到最近的低洼处

**为什么需要能量最小化？**

当我们构建初始构型时（比如手动放置原子、从数据库导入结构），经常会出现：

- **原子重叠**——两个原子靠得太近，Lennard-Jones 势会产生巨大的排斥力
- **不合理的键长/键角**——分子内部张力很大
- **不良接触**——不同分子之间的原子过于靠近

如果我们直接从这样的高能量构型开始跑分子动力学（MD），巨大的力会导致原子获得极大的速度，然后整个系统"爆炸"——数值计算溢出，模拟崩溃。

**能量最小化就是"急救措施"**：在跑 MD 之前，先把系统调到一个合理的低能量状态。

### 势能面 (Potential Energy Surface)

**势能面**（Potential Energy Surface，简称 PES）是一个数学概念：它描述了系统总能量如何随着所有原子位置的变化而变化。

#### 一维类比

想象只有一个原子在一条线上移动。能量随位置变化的曲线可能长这样：

```
能量 E(x)
  |
  |     /\          全局最大值
  |    /  \
  |   /    \    /\
  |  /      \  /  \        局部最小值 (b)
  | /        \/    \      /         \
  |/          局部    \   /           \
  |          最小值    \ /             \
  |           (a)      鞍点            \
  |                        全局最小值    \
  |                          (c)         \___
  +---------------------------------------------> x

  注：a 是局部最小值（不是最低的）
      b 是另一个局部最小值
      c 是全局最小值（能量最低）
```

#### 关键概念

| 概念 | 含义 | 类比 |
|------|------|------|
| **局部最小值** | 某个区域内的最低点，但不一定是全局最低 | 山坡上的一个坑 |
| **全局最小值** | 整个势能面上的最低点 | 最深的山谷 |
| **鞍点** | 某个方向是最低点，但另一个方向是最高点 | 山脊上的一个低点（马鞍形） |
| **梯度（力）** | 势能面在某点的斜率，力 = -梯度 | 山坡的坡度 |

#### 多维情况

对于 N 个原子的三维系统，势能面有 3N 个维度（每个原子有 x, y, z 三个坐标）。这已经无法可视化了，但数学原理是一样的：找到一个所有方向都是"上坡"的点（即局部最小值）。

> **重要提示**：标准的能量最小化算法（如 CG、SD）只能找到**局部最小值**。如果势能面很复杂（有很多坑），系统可能会落入一个不是最低的坑里。找到**全局最小值**需要更高级的方法（如模拟退火、蒙特卡洛等），这超出了本教程的范围。

### 最小化算法

#### 最速下降法 (Steepest Descent)

最速下降法是最直观的算法。核心思想：

1. **计算当前位置的力**（力 = -能量梯度，即最陡下降方向）
2. **沿着力的方向移动一小步**
3. **重复**，直到力足够小（收敛）

```
最速下降法的路径示意（二维 PES 的等高线图）：

    最速下降法路径             收敛过程
    =================        ==================
                               能量
    ->                           |
      \                          |\
       \                         | \
        \                        |  \
         ->                      |   \___
           \                     |       \____
            \                    |            \____
             -->                 |                 \_________
               \                 |
                -->              +-------------------------> 步数
                  \
                   -->

    特点：每步都垂直于等高线     能量稳步下降，但可能很慢
```

**优点：**
- 实现简单，容易理解
- **总是下降**——每一步都确保能量降低（在步长足够小时）
- 鲁棒——不容易发散

**缺点：**
- **收敛慢**——靠近最小值时，梯度变小，步长也变小，进展缓慢
- **锯齿效应**——连续两步的方向互相垂直（数学上可以证明），导致走"之字形"路线

#### 共轭梯度法 (Conjugate Gradient)

共轭梯度法（CG）是对最速下降法的改进。核心区别：

> CG 有"记忆"——它利用前一步的信息来选择更好的搜索方向。

1. **第一步**：和最速下降一样，沿着力的方向移动
2. **后续步骤**：根据当前梯度和前一步的梯度，计算一个**共轭方向**
3. 沿共轭方向移动
4. 重复

```
共轭梯度法的路径示意：

    CG 路径                    两种方法对比
    =========                 ============
                               能量
       -->                      |
         -->                    |\
           ---->                | \
                -------->       |  \
                                |   \___  CG: 更快收敛
    特点：方向更"聪明"           |    \
    不再走纯粹的之字形           |     \____  SD: 收敛较慢
                                |          \____
                                |               \_________
                                +-------------------------> 步数
```

**优点：**
- 收敛速度比最速下降法**快得多**
- 对于 N 个变量的问题，理论上 N 步内收敛（实际中由于数值误差可能更多）
- 计算开销和最速下降法几乎一样

**缺点：**
- 比最速下降法稍复杂
- 在某些特殊情况下可能不如最速下降稳定

**通常推荐使用 CG**——它是 LAMMPS 的默认最小化算法。

#### FIRE 算法 (Fast Inertial Relaxation Engine)

FIRE 是一种较新的最小化方法，它借鉴了分子动力学的思想：

- 给原子加上"虚拟质量"和"虚拟速度"
- 通过动态调整步长和方向来快速收敛
- 结合了 MD 的惯性和最小化的目标

**优点：** 对于某些困难的系统（如严重重叠的原子），FIRE 可能比 CG 和 SD 更快收敛。

**缺点：** 参数调优可能需要更多经验。

### 收敛判据

LAMMPS 的 `minimize` 命令接受以下参数：

```
minimize  etol  ftol  maxiter  maxeval
```

| 参数 | 含义 | 默认行为 |
|------|------|----------|
| **etol** (能量容差) | 连续两步的相对能量变化小于此值时，认为能量收敛 | 通常设为 1.0e-6 或 1.0e-8 |
| **ftol** (力容差) | 所有原子上的最大力小于此值时，认为力收敛 | 通常设为 1.0e-6 或 1.0e-8 |
| **maxiter** (最大迭代次数) | 达到此次数后无论是否收敛都停止 | 根据系统大小设定 |
| **maxeval** (最大评估次数) | 力/能量函数的最多计算次数 | 通常是 maxiter 的 10 倍 |

**如何选择收敛条件？**

- **严格条件**（小 etol/ftol）：结果更精确，但耗时更长
- **宽松条件**（大 etol/ftol）：快但可能不够准确
- 对于准备 MD 的初始构型，通常 **1.0e-6** 就够了
- 对于精确的平衡结构搜索，可能需要 **1.0e-10** 甚至更小

> **提示**：大多数情况下，力收敛（ftol）比能量收敛（etol）更可靠。因为当力很小时，原子几乎不再移动，系统已经处于平衡附近。

### 何时需要能量最小化？

| 场景 | 说明 |
|------|------|
| **MD 之前** | 最常见用途。移除初始构型中的不良接触，防止 MD 崩溃 |
| **构建初始构型后** | 随机放置原子、合并结构、插入缺陷后 |
| **寻找平衡结构** | 确定晶体、分子的最低能量构型（几何优化） |
| **计算性质之前** | 一些性质计算（如弹性常数）需要精确的平衡构型 |
| **力场参数验证** | 检查力场是否能给出合理的平衡结构 |

## 输入脚本逐行解析

以下是 `in.minimize` 脚本的逐行详细解释：

### 初始化部分

```lammps
units           lj
```
使用 Lennard-Jones 无量纲单位。在这种单位制下，长度、能量、质量等都是无量纲的（相对于 sigma、epsilon 等参数归一化）。这简化了教程，避免了物理常数的干扰。

```lammps
atom_style      atomic
```
设置原子样式为 `atomic`（最基本类型）。只记录原子的位置和类型，不记录电荷、分子信息等。

```lammps
lattice         fcc 1.0
```
定义 FCC（面心立方）格子，密度参数为 1.0。FCC 是一种常见的晶体结构，每个晶胞有 4 个原子。参数 1.0 表示使用自然的格子间距（对于 LJ 系统约 1.0 sigma）。

```lammps
region          box block 0 5 0 5 0 5
create_box      1 box
create_atoms    1 box
```
- `region` —— 定义一个长方体区域，尺寸为 5x5x5（以格子常数为单位）
- `create_box` —— 在该区域创建模拟盒子，有 1 种原子类型
- `create_atoms` —— 在盒子中按 FCC 格点填充原子，约生成 500 个原子

### 势函数设置

```lammps
pair_style      lj/cut 2.5
pair_coeff      1 1 1.0 1.0 2.5
```
- `pair_style lj/cut 2.5` —— 使用 Lennard-Jones 势，截断半径为 2.5 sigma
- `pair_coeff` —— 设置参数：epsilon=1.0（势阱深度），sigma=1.0（原子直径），cutoff=2.5

LJ 势的形式：`V(r) = 4*epsilon*[(sigma/r)^12 - (sigma/r)^6]`
- r^(-12) 项：短程排斥（原子靠太近时力急剧增大）
- r^(-6) 项：长程吸引（范德华力）

### 制造重叠

```lammps
group           allatoms type 1
displace_atoms  allatoms random 0.2 0.2 0.2 12345
```
- `group allatoms type 1` —— 将所有类型为 1 的原子归为一组
- `displace_atoms ... random 0.2 0.2 0.2 12345` —— 在 x、y、z 方向各随机偏移 ±0.2 sigma
  - `random` 表示均匀随机分布
  - `12345` 是随机种子，确保结果可重复

FCC 格子最近邻距离约为 1.12 sigma（对于 lattice fcc 1.0）。偏移 0.2 sigma 后，一些原子对的距离可能缩短到 ~0.7 sigma，这已经进入 LJ 势的强排斥区域，产生高能量和巨大的力。

### 最小化部分

```lammps
min_style       cg
```
选择共轭梯度法。

```lammps
min_modify      dmax 0.1
```
限制每步最大位移为 0.1。对于重叠严重的系统，这可以防止步子太大导致数值不稳定。

```lammps
thermo          1
thermo_style    custom step pe ke etotal temp press lx ly lz fmax fnorm
```
每步输出热力学信息。关键输出项：
- `pe` —— 势能，应逐步减小
- `fmax` —— 任何原子上的最大力分量
- `fnorm` —— 所有力的均方根值

```lammps
minimize        1.0e-6 1.0e-6 10000 100000
```
执行最小化：当能量变化 < 1e-6 **或** 最大力 < 1e-6 时停止；最多迭代 10000 步，最多评估 100000 次。

### MD 验证部分

```lammps
velocity        all create 0.5 12345 mom yes rot yes
```
给所有原子分配速度，温度为 0.5（LJ 单位），随机种子为 12345。`mom yes rot yes` 移除系统的总动量和角动量，防止整体漂移。

```lammps
fix             nve_run all nve
```
应用 NVE 系综（恒定粒子数、体积、能量）。这是最简单的系综，不做任何温度或压力控制。

```lammps
run             1000
```
运行 1000 步 MD。如果最小化成功，总能量 `etotal` 应在小范围内波动，不会急剧变化。

## 最小化过程分析

当你运行 `lmp -in in.minimize` 时，会看到大量输出。下面教你如何解读：

### 热力学输出表头

```
Step PotEng KinEng E_mol TotEng Temp Press Lx Ly Lz Fmax Fnorm
```

| 列 | 含义 | 最小化过程中的期望行为 |
|----|------|----------------------|
| Step | 迭代步数 | 从 0 开始递增 |
| PotEng | 势能 | **应该单调递减**（偶尔可能微小回升） |
| KinEng | 动能 | 最小化中始终为 0 |
| TotEng | 总能量 | 等于势能（因为动能=0） |
| Fmax | 最大力 | 应逐渐减小 |
| Fnorm | 力的范数 | 应逐渐减小 |

### 典型的收敛过程

```
Step   PotEng    Fmax     Fnorm
-----  -------   ------   ------
  0     +500.0    10000    5000     <-- 初始：能量极高，力极大
  1     +200.0     5000    2500     <-- 前几步：能量快速下降
  5      +50.0      500     200     <-- 继续下降
 10      +10.0      100      50     <-- 趋于平稳
 20       -5.0       10       5     <-- 接近收敛
 30       -6.5        1      0.5   <-- 更接近
 35       -6.52       0.5    0.2   <-- 收敛！
```

### 如何判断收敛是否成功？

1. **力在减小**：Fmax 和 Fnorm 都在下降
2. **能量在下降**：PotEng 在减少
3. **最终力很小**：Fmax < 你设定的 ftol
4. **脚本正常结束**：没有报错信息

### 常见问题

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 能量先升后降 | 初期步长过大，跳过了最近的最小值 | 减小 `dmax` |
| 能量剧烈震荡 | 原子重叠太严重 | 减小初始偏移，或用更小的 `dmax` |
| 一直不收敛 | 势能面太复杂或系统太大 | 增大 `maxiter`，或放宽收敛条件 |
| "linesearch alpha is zero" | 算法无法找到进一步降低能量的步长 | 正常现象，系统已接近局部最小值 |
| "Lost atoms" | 原子跑出模拟盒子 | 检查初始构型，减小初始偏移 |

## 预期输出

### `in.minimize` 的预期输出

1. **初始状态**：势能为较大的正值（约 +950），力非常大（~10^6）
2. **最小化过程**：
   - 能量快速下降（前 10 步从 +950 降到 ~-6）
   - 然后逐渐变缓，最终收敛到约 -7.6
   - 通常在 20-30 步内基本收敛（取决于偏移程度）
   - 最终能量为负值（对于 LJ FCC，完美晶格的能量约为每个原子 -6.0 到 -8.0）
   - 停止准则可能是 "linesearch alpha is zero"（算法无法进一步降低能量）
3. **MD 验证**：
   - 总能量在 1000 步内基本不变（约 -7.09，波动 < 0.1%）
   - 温度在 0.25-0.40 之间波动（初始设定 0.5，能量守恒后自动调整）

### `in.min_compare` 的预期输出

| 算法 | 典型步数 | 最终能量 | 特点 |
|------|----------|----------|------|
| CG | 较少（约 22 步） | 约 -7.6 | 收敛快，后期效率高 |
| SD | 较多（约 27 步） | 约 -7.6 | 前期下降快，后期有锯齿 |

两种方法应该收敛到**相同的最终能量**（或非常接近），因为它们都是寻找同一个局部最小值。区别在于收敛速度和路径。

> 注意：停止准则可能是 "linesearch alpha is zero"，这意味着算法无法找到能进一步降低能量的步长，即使力的容差（ftol）尚未满足。这在处理严重重叠的原子时是正常的。

### 练习 5：部分原子固定

只最小化部分原子，保持其余原子固定：

```lammps
# 定义两组原子（按位置区分）
region          top block INF INF INF INF 2.5 INF
group           fixed region top
group           mobile subtract all fixed

# 固定一组（设置力为零，使其不动）
fix             freeze fixed setforce 0.0 0.0 0.0

# 只移动另一组
min_style       cg
minimize        1.0e-6 1.0e-6 10000 100000
```
