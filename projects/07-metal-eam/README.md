## 背景知识

### 金属结合的本质

#### 金属键：电子海模型

金属原子的最外层电子（价电子）与原子核的结合较弱。在金属晶体中，这些价电子脱离各自的原子，形成可以在整个晶体中自由移动的"电子气"（或称"电子海"）。失去价电子的原子变成了带正电的离子实，沉浸在电子海中。

```
金属键的示意图：

    ⊕       ⊕       ⊕       ⊕
   /|\  e⁻ /|\  e⁻ /|\  e⁻ /|\
    |   ~~~~ |   ~~~~ |   ~~~~ |
    ⊕       ⊕       ⊕       ⊕
   /|\  e⁻ /|\  e⁻ /|\  e⁻ /|\
    |   ~~~~ |   ~~~~ |   ~~~~ |
    ⊕       ⊕       ⊕       ⊕

  ⊕ = 离子实（带正电）
  e⁻ ~~~ = 自由电子（电子海）
```

这种结合方式赋予金属许多独特性质：

- **高导电性**：自由电子在外加电场下可以定向移动
- **高导热性**：自由电子快速传递热能
- **延展性**：金属键没有方向性，原子层可以相对滑移而不破坏结合
- **金属光泽**：自由电子可以吸收并重新发射可见光

#### 为什么 LJ 势不适合描述金属？

我们在之前的项目中使用的 Lennard-Jones（LJ）势是一个**两体势**（pair potential）：

```
V(r) = 4ε[(σ/r)¹² - (σ/r)⁶]
```

LJ 势只考虑两个原子之间的直接相互作用。它的问题在于：

1. **Cauchy 关系问题**：在只使用两体势的模型中，弹性常数必然满足 C₁₂ = C₄₄（Cauchy 关系）。但真实金属通常不满足这个关系。例如，铜的 C₁₂ ≈ 106 GPa，C₄₈ ≈ 75 GPa，差异显著。

2. **表面能问题**：两体势预测的表面能与体模量的比值与实验不符。

3. **空位形成能问题**：两体势下，空位形成能与弹性模量之间存在固定的数学关系，真实金属不满足这一关系。

4. **内聚能的方向性缺失**：金属键虽然没有共价键那么强的方向性，但多体效应（电子密度的贡献）对于正确描述结合能至关重要。

**根本原因**：金属的结合力来源于电子密度的集体效应，而不仅仅是原子对之间的成对相互作用。这就是我们需要**多体势**（many-body potential）的原因。

### 多体势（Many-Body Potentials）

#### 嵌入原子法（EAM）

嵌入原子法（Embedded Atom Method, EAM）是由 Daw 和 Baskes 在 1984 年提出的，是目前描述金属体系最成功的势函数之一。

##### EAM 的物理图像

想象把一个金属原子"放入"一个由周围电子密度构成的"汤"中。这个原子的能量不仅取决于它与其他原子的距离，还取决于它所处位置的**局部电子密度**。

```
EAM 的物理图像：

        邻居原子的电子密度贡献
              ↓   ↓   ↓
         ───────────────────
        |    ρ(r₁)          |
        |        ↑          |
        |     ρ(r₂)  ● 中心原子 i
        |        ↑          |
        |    ρ(r₃)          |
         ───────────────────
          嵌入能 F(ρ_i)

  ● 中心原子嵌入在由邻居产生的电子密度 ρ_i 中
```

##### EAM 总能量公式

EAM 的总能量由两部分组成：

```
E_total = Σᵢ F(ρᵢ) + (1/2) Σᵢ Σⱼ≠ᵢ φ(rᵢⱼ)
```

各项含义：

| 符号 | 名称 | 物理含义 |
|------|------|----------|
| `F(ρᵢ)` | 嵌入能 | 将原子 i 嵌入电子密度为 ρᵢ 的环境中所需的能量 |
| `ρᵢ` | 电子密度 | 原子 i 处的局部电子密度，由所有邻居原子贡献 |
| `φ(rᵢⱼ)` | 对势 | 原子 i 和 j 之间的短程排斥势（类比离子-离子排斥） |
| `rᵢⱼ` | 原子间距 | 原子 i 和 j 之间的距离 |

##### 电子密度的计算

原子 i 处的电子密度由其所有邻居原子贡献：

```
ρᵢ = Σⱼ≠ᵢ ρⱼ(rᵢⱼ)
```

其中 `ρⱼ(r)` 是原子 j 在距离 r 处产生的电子密度贡献函数。对于纯金属，通常用经验函数拟合。

##### 为什么 EAM 是"多体"势？

关键在于嵌入能 `F(ρᵢ)`：

- `ρᵢ` 依赖于原子 i 的**所有邻居**
- 改变任何一个邻居的位置，都会改变 `ρᵢ`，从而改变嵌入能
- 这意味着一个原子的能量不仅取决于某个特定邻居，还取决于**所有邻居的集体贡献**
- 与 LJ 势（只取决于一个邻居的距离）有本质区别

```
两体势 vs 多体势的对比：

两体势 (LJ):
  Eᵢ = (1/2) Σⱼ V(rᵢⱼ)     ← 只依赖距离

多体势 (EAM):
  Eᵢ = F(ρᵢ) + (1/2) Σⱼ φ(rᵢⱼ)
  其中 ρᵢ = Σⱼ ρⱼ(rᵢⱼ)      ← 嵌入能依赖所有邻居！
```

##### 为什么 EAM 比 LJ 势更准确？

1. **自动满足金属的物理约束**：EAM 不强制 Cauchy 关系，能正确预测弹性常数
2. **正确描述点缺陷**：空位形成能、自间隙原子能等与实验一致
3. **表面性质**：表面能、表面重构的预测更准确
4. **合金扩展**：EAM 可以自然地扩展到多组分合金（称为"合金 EAM"或"eam/alloy"）
5. **计算效率**：虽然比 LJ 势复杂，但仍然是 O(N) 复杂度，计算效率很高

##### EAM 势函数文件格式

EAM 势函数以数据文件的形式提供（不是解析表达式），通常有两种格式：

1. **Dynamo 格式**（`.eam`）：单元素
   - 第1-3行：注释和基本信息
   - 第4行：Nrho, drho, Nr, dr, cutoff 等参数
   - 接下来是嵌入能函数 F(ρ)、电子密度函数 ρ(r)、对势函数 φ(r) 的数据点

2. **setfl 格式**（`.eam.alloy`）：可包含多种元素
   - 可用于合金模拟
   - 文件头包含元素列表

3. **funcfl 格式**（`.eam.fs`）：Finnis-Sinclair 格式

**下载 EAM 势函数文件**：

最权威的势函数库是 NIST 的 Interatomic Potentials Repository：
- 网址：https://www.ctcms.nist.gov/potentials/
- 搜索你需要的金属元素（如 Cu、Fe、Al 等）
- 下载对应的 `.eam` 或 `.eam.alloy` 文件
- 将文件放在 LAMMPS 脚本同目录下

##### 在 LAMMPS 中使用 EAM 势

```lammps
# 单元素 EAM（Dynamo 格式）
pair_style eam
pair_coeff * * Cu_u3.eam

# 多元素 EAM（setfl 格式，用于合金）
pair_style eam/alloy
pair_coeff * * Cu-Ni.eam.alloy Cu Ni
```

`pair_coeff` 的格式说明：
- `* *`: 第一个 `*` 表示所有类型 i，第二个 `*` 表示所有类型 j
- 文件名后跟元素名称列表，顺序必须与 `create_atoms` 中的类型编号对应

#### Finnis-Sinclair 势

Finnis-Sinclair（FS）势是另一种常用的多体势，与 EAM 非常相似，但在嵌入函数的形式上有所不同：

```
EAM:   E = Σᵢ F(ρᵢ) + (1/2) Σ φ(rᵢⱼ)    F 是 ρ 的一般函数

FS:    E = Σᵢ √(ρᵢ) + (1/2) Σ φ(rᵢⱼ)     嵌入函数固定为 √ρ
```

- FS 势的嵌入函数被限制为**平方根形式** `F(ρ) = -√ρ`
- 这种形式在某些金属（特别是过渡金属）上效果很好
- FS 势更早被提出（1980年，Finnis 和 Sinclair），EAM 可以看作是 FS 的推广
- 在 LAMMPS 中使用 `.eam.fs` 格式的文件即可

---

#### Tersoff 势

Tersoff 势是专门为**共价键材料**设计的多体势，适用于：
- 硅（Si）、碳（C）、锗（Ge）
- SiC、SiN 等化合物

Tersoff 势的核心思想是引入一个**键序参数**（bond order），描述化学键的强度如何受周围环境影响：

```
Vᵢⱼ = fC(rᵢⱼ) [fR(rᵢⱼ) + bᵢⱼ fA(rᵢⱼ)]
```

其中 `bᵢⱼ` 是键序参数，取决于原子 i 的配位环境。

在 LAMMPS 中使用：

```lammps
pair_style tersoff
pair_coeff * * Si.tersoff Si
```

**Tersoff vs EAM 的区别**：
- EAM：适合金属，核心是电子密度嵌入
- Tersoff：适合共价材料，核心是键序参数
- 它们都是多体势，都考虑了局部环境对能量的影响

### 晶体结构

金属原子在固体中通常排列成高度有序的晶体结构。最常见的三种金属晶体结构是 FCC、BCC 和 HCP。

#### FCC（面心立方，Face-Centered Cubic）

```
FCC 晶胞示意图：

        ●───────────────●
       /|              /|
      / |             / |    ● = 角上的原子 (8个, 每个被8个晶胞共享 = 1个)
     /  |            /  |    ○ = 面心的原子 (6个, 每个被2个晶胞共享 = 3个)
    ●───────────────●   |    ──────────────────────
    |   |           |   |    每个晶胞共 4 个原子
    |   ○───────────|───○
    |  /            |  /
    | /             | /     配位数 = 12（每个原子有 12 个最近邻）
    |/              |/
    ●───────────────●
```

**FCC 的关键参数**：

| 参数 | 值 |
|------|-----|
| 每个晶胞原子数 | 4 |
| 配位数 | 12 |
| 堆积方式 | ABCABC |
| 致密度 | 74%（理论最大值） |
| 最近邻距离 | a/√2 |

**常见的 FCC 金属**：

| 金属 | 晶格常数 (Å) | 原子量 (g/mol) |
|------|-------------|---------------|
| Cu（铜） | 3.615 | 63.546 |
| Al（铝） | 4.049 | 26.982 |
| Au（金） | 4.078 | 196.967 |
| Ag（银） | 4.086 | 107.868 |
| Ni（镍） | 3.524 | 58.693 |
| Pt（铂） | 3.924 | 195.084 |

**原子半径与晶格常数的关系**：

在 FCC 结构中，原子沿面对角线方向紧密接触。面对角线长度为 `a√2`，上面排列了 4 个原子半径：

```
a√2 = 4r  →  r = a√2 / 4 = a / (2√2)
```

对于铜：r = 3.615 / (2√2) ≈ 1.278 Å

#### BCC（体心立方，Body-Centered Cubic）

```
BCC 晶胞示意图：

        ●───────────────●
       /|              /|
      / |      ●      / |    ● = 角上的原子 (8个 × 1/8 = 1个)
     /  |    (体心)   /  |    ○ = 体心原子 (1个)
    ●───────────────●   |    ──────────────────────
    |   |           |   |    每个晶胞共 2 个原子
    |   |           |   |

    ●───────────────●

| 最近邻距离 | a√3/2 |

#### HCP（六方密堆积，Hexagonal Close-Packed）

```
HCP 晶胞示意图（俯视图）：

      ●───●
     / \ / \
    ●───●───●     ● = 底层原子 (A层)
     \ / \ /      ○ = 顶层原子 (B层，位于A层上方)

| 金属 | a (Å) | c (Å) | c/a |
|------|-------|-------|-----|
| Mg（镁） | 3.209 | 5.211 | 1.624 |
| Zn（锌） | 2.665 | 4.947 | 1.856 |

### 热膨胀

#### 什么是热膨胀？

当温度升高时，几乎所有材料都会膨胀。这种现象称为**热膨胀**。

宏观表现：一根长度为 L 的金属棒，温度升高 ΔT 后，长度变为：

```
L' = L (1 + α · ΔT)
```

其中 `α` 是**线膨胀系数**，单位为 K⁻¹（每开尔文）。

#### 热膨胀的微观原因：非谐振动

热膨胀的根本原因是原子振动的**非谐性**（anharmonicity）。

在简谐振动（理想弹簧）中，原子围绕平衡位置做对称振动，平均位置不变，因此没有热膨胀：

```
简谐振动（对称势能曲线）：

  V(r)
   │    \        /
   │     \      /
   │      \    /     ← 势能曲线完全对称
   │       \  /
   │        \/        ← 平衡位置 r₀
   └──────────────── r
         r₀

  无论温度多高，平均位置始终在 r₀
  → 没有热膨胀
```

真实原子间的势能曲线是**不对称**的：近端的排斥势很陡，远端的吸引势较平缓。这种不对称性导致：

```
非谐振动（真实势能曲线）：

  V(r)
   │   |\        /
   │   | \      /
   │   |  \    /      ← 近端陡峭（强排斥），远端平缓（弱吸引）
   │   |   \  /
   │    \   \/         ← 平衡位置 r₀
   └──────────────── r
         r₀
         ↑
    平均位置随温度升高向右偏移！
    → 产生热膨胀
```

**物理解释**：
- 当温度升高时，原子振动幅度增大
- 由于势能曲线的不对称性，原子向右偏移（远离平衡位置）的幅度比向左偏移（靠近平衡位置）的幅度更大
- 因此**平均位置** `⟨r⟩` 随温度升高而增大
- 这就是热膨胀的微观起源

**如果只有简谐振动**（如理想的弹簧连接的原子），即使温度升高，振动也是对称的，平均位置不变，就不会有热膨胀。正是因为真实势能曲线的**非谐项**（anharmonic terms）才导致了热膨胀。

#### 线膨胀系数

线膨胀系数 `α` 定义为：

```
α = (1/L) × (dL/dT)
```

其中：
- `L` 是材料在参考温度下的长度
- `dL/dT` 是长度随温度的变化率

对于晶体，我们通常用晶格常数 `a` 代替长度 `L`：

```
α = (1/a) × (da/dT)
```

一些常见金属的线膨胀系数：

| 金属 | α (×10⁻⁶ /K) | 说明 |
|------|--------------|------|
| Cu（铜） | 16.5 | 本项目模拟对象 |
| Al（铝） | 23.1 | 膨胀较大 |
| Fe（铁） | 11.8 | 膨胀较小 |
| W（钨） | 4.5 | 膨胀很小，耐高温 |
| Au（金） | 14.2 | 膨胀适中 |

#### 如何从 MD 模拟中测量热膨胀

步骤如下：

1. 在不同温度下运行 NPT 模拟（恒温恒压）
2. 记录每个温度下的平衡晶格常数（从盒子尺寸计算）
3. 绘制 `a(T)` 曲线
4. 从曲线的斜率计算线膨胀系数：`α ≈ (1/a₀) × Δa/ΔT`

```
晶格常数 a(Å)
    │
3.66│                              ●  ← 900K
    │                         ●
3.64│                    ●
    │               ●
3.62│          ●    ← 300K
    │     ●    ← 100K
3.60│
    └──────────────────────────── 温度(K)
      0   100  300  500  700  900

  斜率 = da/dT
  α = (1/a₀) × (da/dT)
```

### 弹性常数简介

弹性常数描述材料在外力作用下的变形行为。对于立方晶体，有 3 个独立的弹性常数：

- **C₁₁**：轴向应力-应变关系
- **C₁₂**：横向耦合
- **C₄₄**：剪切模量

这些常数与工程上常用的模量有如下关系：

| 模量 | 与弹性常数的关系 | 物理含义 |
|------|-----------------|----------|
| 体模量 B | B = (C₁₁ + 2C₁₂) / 3 | 抵抗均匀压缩的能力 |
| 剪切模量 G | G = C₄₄ (立方晶系，Voigt近似) | 抵抗剪切变形的能力 |
| 杨氏模量 E | E = 9BG / (3G + B) | 抵抗拉伸的能力 |
| 泊松比 ν | ν = (3B - 2G) / (2(3B + G)) | 横向收缩与纵向伸长之比 |

**如何在 LAMMPS 中计算弹性常数？**

基本思路是对体系施加小的应变（通过 `fix deform` 改变盒子形状），然后测量应力响应。弹性常数 Cᵢⱼ = σᵢ / εⱼ。

```lammps
# 示例：计算 C₁₁ 的思路
# 1. 对 x 方向施加小的拉伸应变 εxx
# 2. 测量 x 方向的应力 σxx
# 3. C₁₁ = σxx / εxx

fix deform all deform 1 x erate 0.001 remap x
```

## 输入脚本逐行解析

### in.cu_crystal — 铜晶体 NPT 模拟

#### 初始化部分

```lammps
clear                          # 清除所有之前的设置，从头开始
units metal                    # 使用金属单位系统
                               #   距离=Å, 能量=eV, 时间=ps, 温度=K, 压力=bar
atom_style atomic              # 最简单的原子样式（无电荷、无键）
```

#### 晶格与盒子

```lammps
lattice fcc 3.615              # 定义 FCC 晶格，晶格常数 3.615 Å（铜）
region box block 0 10 0 10 0 10 units lattice
                               # 定义长方体区域: 10×10×10 个晶胞
                               # 实际尺寸: 36.15 × 36.15 × 36.15 Å
create_box 1 box               # 创建模拟盒子，1种原子类型
create_atoms 1 box             # 在盒子中按晶格填充原子
                               # 总原子数 = 10³ × 4 = 4000 个
mass 1 63.546                  # 设置类型1的质量 = 63.546 g/mol（铜的原子量）
```

#### 力场设置

```lammps
pair_style lj/cut 4.0          # LJ 12-6 势，截断半径 4.0 Å
pair_coeff 1 1 0.343 2.54      # 类型1-1的 LJ 参数:
                               #   ε = 0.343 eV, σ = 2.54 Å
                               #   （近似铜的参数，仅供教学）
neighbor 2.0 bin               # 邻居列表皮肤距离 2.0 Å
```

> **切换到 EAM 势**：如果你下载了 EAM 势函数文件（如 `Cu_u3.eam`），只需将上面两行改为：
> ```lammps
> pair_style eam
> pair_coeff * * Cu_u3.eam
> ```

#### 输出与运行

```lammps
thermo 100                     # 每 100 步输出热力学信息
thermo_style custom step temp pe ke etotal press vol lx density
                               # 输出: 步数、温度、势能、动能、总能、压力、体积、盒子长度、密度

dump myDump all atom 100 cu_crystal.lammpstrj
                               # 每 100 步输出原子轨迹（OVITO 可视化用）

minimize 1.0e-4 1.0e-6 1000 10000
                               # 能量最小化: 消除原子重叠
                               # 收敛标准: 能量变化 < 10⁻⁴ eV, 力 < 10⁻⁶ eV/Å

timestep 0.001                 # 时间步长 0.001 ps = 1 fs

fix myNPT all npt temp 300 300 0.1 iso 0 0 1.0
                               # NPT 系综:
                               #   温度 300K（恒温）
                               #   压力 0 bar（各向同性恒压）
                               #   温度阻尼 0.1 ps, 压力阻尼 1.0 ps

variable lat equal lx/10.0    # 定义变量: 晶格常数 = x方向盒子长度 / 10
fix myAve all ave/time 1 10 100 v_lat file lattice.dat mode scalar
                               # 每 100 步输出晶格常数的时间平均到文件

run 10000                      # 运行 10000 步 = 10 ps
```

### in.cu_thermal — 多温度热膨胀

关键区别在于逐温度循环：

```lammps
# 对每个温度点：
fix npt_XXX all npt temp T_start T_end 0.1 iso 0 0 1.0
                               # 设置 NPT，温度从 T_start 到 T_end
fix ave_XXX all ave/time 1 10 500 v_lat file lattice_XXXK.dat mode scalar
                               # 记录晶格常数
run 5000                       # 运行 5000 步
unfix npt_XXX                  # 删除 fix，准备下一个温度
unfix ave_XXX
```

逐步升温的策略确保体系稳定，避免温度突变导致的非物理行为。

### 用 Python 分析热膨胀数据

```python
import numpy as np
import matplotlib.pyplot as plt

# 各温度的晶格常数文件
temps = [100, 300, 500, 700, 900]
lattice_constants = []

for T in temps:
    filename = f'lattice_{T}K.dat'
    try:
        data = np.loadtxt(filename, skiprows=2)  # 跳过注释行
        # 取最后一列（晶格常数），计算后半段的平均值（平衡后）
        n = len(data)
        avg_lat = np.mean(data[n//2:, 1])  # 后半段平均
        lattice_constants.append(avg_lat)
        print(f"T = {T} K: a = {avg_lat:.4f} Å")
    except FileNotFoundError:
        print(f"文件 {filename} 未找到，请先运行 lmp -in in.cu_thermal")

# 绘制热膨胀曲线
if lattice_constants:
    plt.figure(figsize=(8, 6))
    plt.plot(temps, lattice_constants, 'bo-', markersize=8, linewidth=2)
    plt.xlabel('Temperature (K)', fontsize=14)
    plt.ylabel('Lattice constant (Å)', fontsize=14)
    plt.title('Thermal Expansion of Copper (LJ model)', fontsize=14)
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.savefig('thermal_expansion.png', dpi=150)
    plt.show()

    # 计算线膨胀系数
    a0 = lattice_constants[0]  # 参考温度(100K)的晶格常数
    for i in range(1, len(temps)):
        da = lattice_constants[i] - lattice_constants[0]
        dT = temps[i] - temps[0]
        alpha = (1.0 / a0) * (da / dT)
        print(f"α (100K ~ {temps[i]}K) = {alpha*1e6:.2f} × 10⁻⁶ /K")
```

```lammps

# 每步记录 stress/atom 或 pressure

```
