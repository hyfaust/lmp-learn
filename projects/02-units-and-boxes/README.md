# 项目 02：单位制与模拟盒子

## 学习目标

完成本项目后，你将能够：

1. **理解 LAMMPS 的 8 种单位制**及其适用场景，能够根据模拟体系正确选择单位制，并知道每种单位制下质量、距离、时间、能量、速度、力、温度、压力的量纲和默认时间步长
2. **掌握约化单位（LJ）与有量纲单位（real、metal 等）之间的转换关系**，理解"同一物理系统，不同数字表达"的核心思想，能够手动完成力场参数、温度、截断半径等在不同单位制之间的换算
3. **熟练配置模拟盒子**，包括维度设置（2D/3D）、边界条件（periodic/free/shrink-wrap）、晶格类型（fcc/bcc/sc/diamond/hcp）与密度
4. **学会使用 `read_data` 命令**导入实验或理论结构数据，理解 data 文件的基本格式
5. **能够对比不同单位制下同一物理系统的模拟结果**，验证单位转换的正确性，识别常见的单位制使用错误

## 背景知识

### LAMMPS 单位制详解

在 LAMMPS 中，`units` 命令是输入脚本中**最早**需要设定的命令之一。它决定了整个模拟中所有物理量的单位——质量、距离、时间、能量、速度、力、温度、压力等。

> **核心原则**：LAMMPS 不会帮你做单位转换。如果你在 `units real` 下写 `mass 1 1.0`，LAMMPS 会认为原子质量是 1.0 g/mol（大约是氢原子的质量），而不是 1.0 无量纲。
>
> 选错单位制不会让 LAMMPS 报错，但会产生完全错误的物理结果——这是初学者最容易犯的错误之一。

LAMMPS 提供 8 种单位制，下面逐一详细介绍。

---

#### 1. `lj` — 约化单位（Lennard-Jones Reduced Units）

> 最适合：教学演示、通用 LJ 流体研究、算法开发、相图研究

这是理论物理和统计力学中最常用的无量纲化方案。以 Lennard-Jones 势的两个特征参数（能量 ε 和长度 σ）为基准，将所有物理量归一化。玻尔兹曼常数被设为 k_B = 1。

| 物理量 | 单位 | 说明 | 以氩（Ar）为例 |
|--------|------|------|----------------|
| 质量 | — (无量纲) | m* = m / m_ref | m* = 1.0，对应 39.948 amu |
| 距离 | — (无量纲) | r* = r / σ | σ* = 1.0，对应 3.405 Å |
| 时间 | — (无量纲) | t* = t / τ，τ = σ√(m/ε) | τ = 1.0，对应 2.157 ps |
| 能量 | — (无量纲) | E* = E / ε | ε* = 1.0，对应 1.654×10⁻²¹ J |
| 速度 | — (无量纲) | v* = v / (σ/τ) | 对应 1.579×10³ m/s |
| 力 | — (无量纲) | f* = f / (ε/σ) | — |
| 温度 | — (无量纲) | T* = k_B T / ε，k_B = 1 | T* = 1.0 对应 119.8 K |
| 压力 | — (无量纲) | P* = P σ³ / ε | P* = 1.0 对应 41.9 MPa |
| 密度 | — (无量纲) | ρ* = ρ σ³ | ρ* = 0.8442 对应液态氩密度 |

- **默认时间步长**：0.005 τ
- **玻尔兹曼常数**：k_B = 1（这是 LJ 约化的核心特征）
- **优势**：参数简洁（ε=1, σ=1, m=1），便于理论分析，结果具有普适性
- **劣势**：无法直接读出实际物理量，需要事后换算

**LJ 约化单位与国际单位的完整转换表（以氩为例）**：

| 约化量 | 约化值 | 实际物理值 |
|--------|--------|-----------|
| 1 σ | 1.0 | 3.405 Å = 3.405 × 10⁻¹⁰ m |
| 1 ε | 1.0 | 1.654 × 10⁻²¹ J = 119.8 K × k_B |
| 1 m | 1.0 | 39.948 amu = 6.634 × 10⁻²⁶ kg |
| 1 τ | 1.0 | 2.157 ps = 2.157 × 10⁻¹² s |
| T* = 1.0 | 1.0 | 119.8 K |
| P* = 1.0 | 1.0 | 41.9 MPa |

#### 2. `real` — 真实单位（分子动力学标准）

> 最适合：有机分子、蛋白质、聚合物、水溶液等分子体系

这是分子动力学中最常用的单位制，几乎所有经典分子力场（AMBER、CHARMM、OPLS、GAFF）的参数都以此为单位。

| 物理量 | 单位 | 说明 |
|--------|------|------|
| 质量 | g/mol | 原子量（如 C = 12.011, O = 15.999, Ar = 39.948） |
| 距离 | Å（埃） | 1 Å = 1 × 10⁻¹⁰ m |
| 时间 | fs（飞秒） | 1 fs = 1 × 10⁻¹⁵ s |
| 能量 | kcal/mol | 千卡每摩尔 |
| 速度 | Å/fs | — |
| 力 | kcal/(mol·Å) | — |
| 温度 | K（开尔文） | — |
| 压力 | atm（标准大气压） | 1 atm = 101.325 kPa |

- **默认时间步长**：1.0 fs
- **玻尔兹曼常数**：k_B = 0.001987206 kcal/(mol·K)
- **典型力场参数例子**：TIP3P 水模型中 O-H 键长 = 0.9572 Å，键力常数 = 450 kcal/(mol·Å²)

---

#### 3. `metal` — 金属单位（材料科学标准）

> 最适合：金属、合金、半导体、陶瓷等无机材料

这是固体物理和材料科学中最常用的单位制，EAM、Tersoff、MEAM 等势函数的参数通常以此为单位。

| 物理量 | 单位 | 说明 |
|--------|------|------|
| 质量 | g/mol | 与 real 相同 |
| 距离 | Å（埃） | 与 real 相同 |
| 时间 | ps（皮秒） | 1 ps = 1 × 10⁻¹² s ← 注意与 real 不同！ |
| 能量 | eV（电子伏特） | 1 eV = 1.602 × 10⁻¹⁹ J ← 注意与 real 不同！ |
| 速度 | Å/ps | — |
| 力 | eV/Å | — |
| 温度 | K（开尔文） | — |
| 压力 | bar（巴） | 1 bar = 1 × 10⁵ Pa |

- **默认时间步长**：0.001 ps = 1 fs
- **玻尔兹曼常数**：k_B = 8.617 × 10⁻⁵ eV/K
- **典型例子**：铜（Cu）晶格常数 a = 3.615 Å，使用 EAM 势

---

#### 4. `si` — 国际单位制（SI）

> 最适合：需要与工程软件对接、多物理场耦合、宏观连续介质力学

| 物理量 | 单位 | 说明 |
|--------|------|------|
| 质量 | kg | 千克 |
| 距离 | m | 米 |
| 时间 | s | 秒 |
| 能量 | J（焦耳） | — |
| 速度 | m/s | — |
| 力 | N（牛顿） | — |
| 温度 | K | — |
| 压力 | Pa（帕斯卡） | — |

- **默认时间步长**：1.0 × 10⁻⁸ s（10 ns）
- **玻尔兹曼常数**：k_B = 1.381 × 10⁻²³ J/K
- **注意**：原子尺度的距离约为 10⁻¹⁰ m，在 SI 单位下数值极小，容易出现浮点精度问题。一般不推荐用于原子尺度的 MD 模拟。

---

#### 5. `cgs` — 厘米-克-秒单位制

> 最适合：与使用 CGS 单位的实验数据对接、天文物理模拟

| 物理量 | 单位 | 说明 |
|--------|------|------|
| 质量 | g | 克 |
| 距离 | cm | 厘米 |
| 时间 | s | 秒 |
| 能量 | erg（尔格） | 1 erg = 1 × 10⁻⁷ J |
| 速度 | cm/s | — |
| 力 | dyne（达因） | 1 dyne = 1 × 10⁻⁵ N |
| 温度 | K | — |
| 压力 | dyne/cm² | — |

- **默认时间步长**：1.0 × 10⁻⁸ s
- **玻尔兹曼常数**：k_B = 1.381 × 10⁻¹⁶ erg/K
- **适用场景**：胶体模拟、某些习惯使用 CGS 的经典力学计算

---

#### 6. `electron` — 原子单位（Bohr 单位）

> 最适合：与量子化学计算耦合、路径积分分子动力学（PIMD）

| 物理量 | 单位 | 说明 |
|--------|------|------|
| 质量 | amu | 原子质量单位（1 amu = 1.661 × 10⁻²⁷ kg） |
| 距离 | Bohr（玻尔半径） | a₀ = 0.52918 Å |
| 时间 | — | 1 atu = ℏ/Eₕ ≈ 2.419 × 10⁻¹⁷ s |
| 能量 | Hartree（哈特里） | Eₕ = 27.211 eV = 627.5 kcal/mol |
| 速度 | Bohr/atu | — |
| 温度 | K | — |
| 电荷 | e（基本电荷） | — |

- **默认时间步长**：0.001 atu ≈ 0.024 fs（极小的时间步长，反映电子运动的超快时间尺度）
- **玻尔兹曼常数**：k_B = 3.167 × 10⁻⁶ Hartree/K
- **适用场景**：路径积分 MD、核量子效应研究、与 DFT 方法耦合的混合模拟

---

#### 7. `micro` — 介观尺度单位

> 最适合：粗粒化模型、耗散粒子动力学（DPD）、胶体模拟

| 物理量 | 单位 | 说明 |

- **适用场景**：DPD 粗粒化模拟、胶体粒子动力学

### 单位制选择指南

选择单位制的原则很简单——**你的力场参数的单位决定了你该用哪种单位制**：

```
你的研究对象是什么？
│
├── 通用 LJ 流体 / 教学演示 / 算法开发
│   └── 使用 `lj` (约化单位)
│
├── 有机分子 / 蛋白质 / 聚合物 / 水溶液
│   └── 使用 `real` (g/mol, Å, fs, kcal/mol)
│       对应力场: AMBER, CHARMM, OPLS, GAFF
│
├── 金属 / 合金 / 半导体 / 陶瓷
│   └── 使用 `metal` (g/mol, Å, ps, eV)
│       对应势函数: EAM, MEAM, Tersoff, ReaxFF
│
├── 纳米材料 / 纳米流体
│   └── 考虑 `nano` 或 `metal`
│
├── 胶体 / 介观粗粒化
│   └── 考虑 `micro` 或 `cgs`
│
├── 量子化学耦合 / 路径积分 MD
│   └── 考虑 `electron`
│
└── 不确定
    └── 查阅你使用的力场/势函数的文献，看作者用什么单位制
```

**黄金法则**：如果你的势函数参数是以 eV 和 Å 给出的，就用 `metal`；如果是 kcal/mol 和 Å，就用 `real`；如果是无量纲的，就用 `lj`。

### 模拟盒子

#### 维度（dimension）— 2D vs 3D

LAMMPS 默认运行**三维（3D）**模拟（`dimension 3` 是默认值，不需要显式写）。如果需要二维模拟，需要在脚本开头显式声明：

```bash
dimension 2
```

**2D 模拟的注意事项**：

- 粒子的 z 坐标应固定在 z 方向盒子长度的一半处
- z 方向的边界条件通常设为 `p`（周期性）或 `f`（固定），但不能设 `m`
- 速度的 z 分量和力的 z 分量会被自动清零
- 需要使用 2D 晶格类型（如 `sq` 简单正方、`hex` 六方）
- 适用于：薄膜、界面、二维材料（石墨烯）、颗粒流

```bash
# 2D 模拟示例
dimension 2
boundary p p f        # z 方向用 f（固定），不能用 s（收缩包裹）
lattice sq 0.8        # 使用正方晶格（2D）
```

本项目的所有脚本都使用默认的 3D 模拟。

---

#### 边界条件（boundary）

`boundary` 命令控制模拟盒子在 x、y、z 三个方向上的边界行为。每个方向可以独立设定。

##### `p` — periodic（周期性边界）

```
         ┌─────────────────┐
粒子 A → │  →  →  →  →  →  │ →  从对面重新进入
         │                 │
         │  ●  ●  ●  ●  ● │    盒子内粒子自由运动
         │                 │
粒子 B ← │  ←  ←  ←  ←  ← │ ←  从对面重新进入
         └─────────────────┘
         ↑               ↑
         粒子穿过边界后从对面出来
```

粒子从盒子一端离开后，会从对面一端重新进入，模拟了无限大的周期性重复系统。**这是最常用的边界条件，绝大多数模拟都使用 `p p p`**。

##### `f` — fixed（固定边界）

```
         ╔═════════════════╗  ← 不可穿透的墙壁
粒子 A → ║  →  →  →  ✕     ║
         ║                 ║  ← 粒子 A 撞墙后反弹
         ║  ●  ●  ●  ●    ║
         ║                 ║
         ║     ✕  ← ← ← ← ║  ← 粒子 B 撞墙后反弹
         ╚═════════════════╝  ← 不可穿透的墙壁
```

粒子不能穿过边界，到达边界时会被反射。盒子大小固定不变。适用于纳米颗粒、表面等非周期性体系。

##### `s` — shrink-wrap（收缩包裹边界）

```
  初始盒子:                  运动后:
  ┌─────────────────┐       ┌────────┐
  │                 │       │ ●  ●   │
  │  ●         ●    │  →→→  ├────────┤  ← 盒子自动收缩
  │                 │       │        │    包裹住所有粒子
  │         ●       │       │ ●   ●  │
  │                 │       └────────┘
  └─────────────────┘
```

边界会自动调整到刚好包裹住所有粒子的位置。盒子大小会随原子的移动而动态变化。适用于团簇、液滴等有限体系。

##### `m` — 最小收缩包裹边界

与 `s` 类似，但盒子大小不会小于一个设定的最小值，防止盒子在某些方向上退化为零厚度。这是更安全的收缩包裹选项。

**常见边界条件组合**：

| 组合 | 含义 | 典型应用 |
|------|------|---------|
| `p p p` | 完全周期性 | 体相材料、液体、气体（最常用） |
| `p p f` | z 方向有限 | 表面模拟、薄膜 |
| `p p s` | z 方向自适应 | 液滴、团簇在表面上 |
| `f f f` | 完全非周期性 | 纳米颗粒、气相团簇 |

#### 晶格（lattice）

`lattice` 命令定义了用于创建原子初始位置的晶格类型和密度。

```bash
lattice <类型> <密度>
```

##### 支持的晶格类型

**fcc — 面心立方（Face-Centered Cubic）**

```
       ●───────●
      /|      /|
     / |     / |      ● = 角落原子（8 × 1/8 = 1）
    ●───────●  |      ○ = 面心原子（6 × 1/2 = 3）
    |  ○────|──○      每个晶胞共 4 个原子
    | /     | /       配位数 = 12
    |/      |/        堆积效率 = 74%
    ○───────●
```

- 典型材料：Al, Cu, Au, Ag, Ni, Pb, Pt
- 氩在低温下也形成 fcc 晶体
- 晶格常数 a 与最近邻距离 d 的关系：d = a/√2

**bcc — 体心立方（Body-Centered Cubic）**

```
       ●───────●
      /|      /|
     / |     / |
    ●───────●  |
    |  ◉────|──●      ● = 角落原子（8 × 1/8 = 1）
    | /     | /       ◉ = 体心原子（1 × 1 = 1）
    |/      |/        每个晶胞共 2 个原子
    ●───────●         配位数 = 8
                      堆积效率 = 68%
```

- 典型材料：Fe (α-Fe), W, Cr, Mo, Na, K, Ba
- 晶格常数 a 与最近邻距离 d 的关系：d = a√3/2

**sc — 简单立方（Simple Cubic）**

```
       ●───────●
      /       /
     /       /        ● = 原子（8 × 1/8 = 1）
    ●───────●         每个晶胞共 1 个原子
    |       |         配位数 = 6
    |       |         堆积效率 = 52%
    ●───────●
```

- 典型材料：Po（钋）是自然界中极少数呈现简单立方结构的元素
- 主要用于理论研究和教学

**diamond — 金刚石结构**

```
       ●───────●
      /|      /|
     / |     / |      实际上是两个 fcc 子晶格嵌套：
    ●───────●  |      一个在 (0,0,0)，另一个在 (1/4, 1/4, 1/4)
    |  ○────|──○      每个晶胞共 8 个原子
    | /     | /       配位数 = 4（四面体配位）
    |/      |/        堆积效率 = 34%
    ○───────●
```

- 典型材料：C（金刚石）、Si、Ge、α-Sn
- 重要的半导体结构

**hcp — 六方密堆积（Hexagonal Close-Packed）**

```
        ○───○───○
       / \ / \ / \       ○ = A 层原子
      ○───●───○───●      ● = B 层原子
       \ / \ / \ /       A 层和 B 层交替堆叠
        ○───○───○         每个晶胞 2 个原子
```

- 典型材料：Mg, Ti, Zn, Co, Zr
- 配位数 = 12，堆积效率 = 74%（与 fcc 相同，都是密堆积）
- 理想 c/a 比 = √(8/3) ≈ 1.633

##### 密度参数的含义

密度参数的含义取决于当前的单位制：

- **`lj` 单位**：输入的是约化数密度 ρ* = ρ·σ³（无量纲）
  ```
  lattice fcc 0.8442    # 每 σ³ 体积中有 0.8442 个原子
  ```

- **其他有量纲单位**：输入的是原子数密度，单位为 原子/ų
  ```
  lattice fcc 0.02138   # 0.02138 原子/ų
  ```

**密度换算关系**：
```
ρ (原子/ų) = ρ* / σ³ = 0.8442 / (3.405)³ = 0.8442 / 39.48 = 0.02138
```

**密度与盒子大小的关系**：
```
region simbox block -4 4 -4 4 -4 4
# -4 到 4 的单位是"晶格常数"，不是 σ，也不是 Å！
# fcc 在此密度下晶格常数 a ≈ 1.68σ ≈ 5.74 Å
# 盒子边长 = 8 × 5.74 Å ≈ 45.9 Å
# 原子数 ≈ 密度 × 体积 ≈ 2048 个
```

## 输入脚本逐行解析

本项目包含三个输入脚本，它们描述的是**完全相同的物理系统**——类氩流体（Argon-like fluid），但使用了三种不同的单位制。下面逐一解析。

### 脚本 1：`in.lj_units` — LJ 约化单位

这个脚本使用 Lennard-Jones 约化单位，所有参数都是无量纲的。

```bash
# ---- 初始化 ----
clear                           # 清除之前可能存在的所有定义

# ---- 单位制设定 ----
units lj                        # 使用 LJ 约化单位（无量纲）
                                # 质量=m_ref, 距离=σ, 时间=τ, 能量=ε, k_B=1

# ---- 原子类型 ----
atom_style atomic               # "atomic"：最简单的球形原子
                                # 无电荷、无键连信息，适用于单原子系统

# ---- 模拟盒子 ----
boundary p p p                  # 三个方向都是周期性边界 (periodic)
                                # 粒子从盒子一边出去，从对面一边重新进入

# ---- 力场模型 ----
pair_style lj/cut 2.5          # Lennard-Jones 12-6 势：V(r) = 4ε[(σ/r)¹² - (σ/r)⁶]
                                # 截断半径 = 2.5（即 2.5σ，经典推荐值）
                                # 超过此距离的相互作用被忽略

# ---- 邻居列表 ----
neighbor 0.3 bin                # 邻居列表的"皮肤"距离 = 0.3（即 0.3σ）
                                # bin：使用空间分箱法加速邻居搜索
neigh_modify every 1 delay 0 check yes
                                # every 1：每 1 步检查是否需要重建邻居列表
                                # delay 0：不延迟重建
                                # check yes：根据原子位移判断是否需要重建

# ---- 晶格与模拟盒子创建 ----
lattice fcc 0.8442              # FCC 晶格，约化密度 ρ* = 0.8442
                                # 这是典型的 LJ 液体密度
                                # 晶格常数 a = (4/ρ*)^(1/3) ≈ 1.68σ

region simbox block -4 4 -4 4 -4 4
                                # 定义矩形区域
                                # -4 到 4 是晶格常数的倍数（不是 σ！）
                                # 实际盒子边长 ≈ 8 × 1.68σ ≈ 13.4σ

create_box 1 simbox             # 在 simbox 区域创建模拟盒子
                                # 1：1 种原子类型

create_atoms 1 box              # 在盒子内按 FCC 晶格填充第 1 种原子
                                # 8×8×8 个晶胞 × 4 原子/晶胞 = 2048 个原子

# ---- 质量设定 ----
mass 1 1.0                      # 第 1 种原子的质量 = 1.0（约化质量，无量纲）
                                # 因为 m_ref = m(氩) = 39.948，所以 m* = 39.948/39.948 = 1.0

# ---- 力场参数 ----
pair_coeff 1 1 1.0 1.0          # 类型 1 与类型 1 的相互作用：
                                #   ε* = 1.0（约化能量，LJ 单位下为 1）
                                #   σ* = 1.0（约化距离，LJ 单位下为 1）
                                # 截断半径继承 pair_style 中的 2.5

# ---- 热力学输出设定 ----
thermo 100                      # 每 100 步输出一次热力学信息到终端

thermo_style custom step temp press pe ke etotal density
                                # step：当前时间步
                                # temp：温度 T*（无量纲）
                                # press：压力 P*（无量纲）
                                # pe：势能（约化单位）
                                # ke：动能（约化单位）
                                # etotal：总能量 = PE + KE（NVE 下应守恒）
                                # density：数密度 ρ*（无量纲）

# ---- 速度初始化 ----
velocity all create 1.0 12345 dist gaussian
                                # 给所有原子随机赋予初始速度
                                # 目标温度 T* = 1.0（对应 119.8 K）
                                # 12345：随机数种子（固定种子可重现结果）
                                # dist gaussian：速度服从麦克斯韦-玻尔兹曼分布

# ---- 轨迹输出 ----
dump mydump all atom 100 dump.lammpstrj
                                # 每 100 步输出一帧原子轨迹
                                # mydump：dump 的名称标识
                                # all：输出所有原子
                                # atom：原子格式（每个原子一行）
                                # dump.lammpstrj：输出文件名

# ---- 时间积分器 ----
fix 1 all nve                   # NVE 系综（微正则系综）
                                # 粒子数 N、体积 V、能量 E 守恒
                                # 使用 Velocity-Verlet 算法积分牛顿运动方程

# ---- 时间步长 ----
timestep 0.005                  # dt = 0.005τ ≈ 0.005 × 2.157 ps ≈ 0.0108 ps ≈ 10.8 fs
                                # 这是 LJ 模拟中常用的步长（太大导致积分不稳定）

# ---- 运行模拟 ----
run 1000                        # 运行 1000 步
                                # 总模拟时间 = 1000 × 0.005τ = 5τ ≈ 10.8 ps
```

**LJ 脚本的单位转换参考**：

| LJ 约化值 | 实际物理值（氩） |
|-----------|-----------------|
| T* = 1.0 | T = 119.8 K |
| ρ* = 0.8442 | ρ = 0.02138 原子/ų |
| PE* ≈ -5.5 | PE ≈ -1.31 kcal/mol ≈ -0.0568 eV |
| dt = 0.005 | dt ≈ 10.8 fs |
| 总时间 = 5τ | 总时间 ≈ 10.8 ps |

### 脚本 2：`in.real_units` — 真实单位

这个脚本描述与 LJ 脚本**完全相同的物理系统**，但所有参数都用 real 单位制表达。

```bash
# ---- 初始化 ----
clear

# ---- 单位制设定 ----
units real                      # real 单位制：g/mol, Å, fs, kcal/mol, K, atm
                                # 与 lj 不同，所有参数都要用有量纲的物理量

atom_style atomic
boundary p p p

# ---- 力场模型 ----
pair_style lj/cut 8.5125       # 截断半径 = 2.5σ = 2.5 × 3.405 Å = 8.5125 Å
                                # 注意：LJ 中写 2.5，real 中必须写 8.5125！

# ---- 邻居列表 ----
neighbor 2.0 bin                # 皮肤距离 = 0.3σ ≈ 0.3 × 3.405 ≈ 1.0 Å
                                # 这里取 2.0 Å，在合理范围内
neigh_modify every 1 delay 0 check yes

# ---- 晶格与模拟盒子创建 ----
lattice fcc 0.02138             # 数密度 = 0.02138 原子/ų
                                # 由 LJ 的 ρ* = 0.8442 换算：
                                # ρ = ρ*/σ³ = 0.8442 / (3.405)³ = 0.02138

region simbox block -4 4 -4 4 -4 4
                                # 同样是 -4 到 4 个晶格常数
                                # 此密度下晶格常数 a ≈ 5.74 Å
                                # 盒子边长 ≈ 8 × 5.74 ≈ 45.9 Å

create_box 1 simbox
create_atoms 1 box

# ---- 质量设定 ----
mass 1 39.948                   # 氩的原子量 = 39.948 g/mol
                                # LJ 中写 1.0，real 中必须写 39.948！

# ---- 力场参数 ----
pair_coeff 1 1 0.2381 3.405     # ε = 0.2381 kcal/mol, σ = 3.405 Å
                                # 由 LJ 的 ε* = 1.0 换算：
                                # ε = 119.8 K × 0.001987 kcal/(mol·K) = 0.2381 kcal/mol

# ---- 热力学输出设定 ----
thermo 100
thermo_style custom step temp press pe ke etotal density
                                # temp：温度（K，开尔文）
                                # press：压力（atm，标准大气压）
                                # pe/ke/etotal：能量（kcal/mol）
                                # density：质量密度（g/cm³）—— 注意！real 下是质量密度

# ---- 速度初始化 ----
velocity all create 119.8 12345 dist gaussian
                                # 目标温度 = 119.8 K（与 LJ 中 T*=1.0 相同的物理温度）

# ---- 轨迹输出 ----
dump mydump all atom 100 dump_real.lammpstrj

# ---- 时间积分器 ----
fix 1 all nve

# ---- 时间步长 ----
timestep 10.0                   # 10.0 fs = 0.005 × 2157 fs
                                # real 单位下 timestep 的单位是 fs

# ---- 运行模拟 ----
run 1000                        # 1000 × 10 fs = 10 ps
                                # 与 LJ 脚本的物理时间基本相同
```

**与 LJ 脚本的关键差异对照表**：

| 参数 | LJ 脚本 | Real 脚本 | 物理意义相同？ |
|------|---------|-----------|--------------|
| `units` | `lj` | `real` | — |
| `mass` | `1.0` | `39.948` | 1.0 × 39.948 = 39.948 g/mol ✓ |
| `pair_coeff ε` | `1.0` | `0.2381` | 1.0 × 0.2381 = 0.2381 kcal/mol ✓ |
| `pair_coeff σ` | `1.0` | `3.405` | 1.0 × 3.405 = 3.405 Å ✓ |
| `cutoff` | `2.5` | `8.5125` | 2.5 × 3.405 = 8.5125 Å ✓ |
| `velocity temp` | `1.0` | `119.8` | 1.0 × 119.8 = 119.8 K ✓ |
| `timestep` | `0.005` | `10.0` | 0.005 × 2157 fs ≈ 10 fs ✓ |
| `lattice density` | `0.8442` | `0.02138` | 0.8442/39.48 = 0.02138/ų ✓ |

### 脚本 3：`in.metal_units` — 金属单位

这个脚本同样描述相同的物理系统，使用 metal 单位制。

```bash
# ---- 初始化 ----
clear

# ---- 单位制设定 ----
units metal                     # metal 单位制：g/mol, Å, ps, eV, K, bar

atom_style atomic
boundary p p p

# ---- 力场模型 ----
pair_style lj/cut 8.5125       # 与 real 相同：截断半径 8.5125 Å
                                # 因为 metal 和 real 的长度单位都是 Å

# ---- 邻居列表 ----
neighbor 2.0 bin
neigh_modify every 1 delay 0 check yes

# ---- 晶格与模拟盒子创建 ----
lattice fcc 0.02138             # 与 real 相同：0.02138 原子/ų
                                # 因为 metal 和 real 的长度单位都是 Å
region simbox block -4 4 -4 4 -4 4
create_box 1 simbox
create_atoms 1 box

# ---- 质量设定 ----
mass 1 39.948                   # 与 real 相同：39.948 g/mol

# ---- 力场参数 ----
pair_coeff 1 1 0.01032 3.405    # ε = 0.01032 eV, σ = 3.405 Å
                                # 由 real 的 ε = 0.2381 kcal/mol 换算：
                                # 0.2381 × 0.04336 = 0.01032 eV
                                # 由温度换算验证：
                                # 119.8 K × 8.617×10⁻⁵ eV/K = 0.01032 eV ✓

# ---- 热力学输出设定 ----
thermo 100
thermo_style custom step temp press pe ke etotal density
                                # press：压力（bar）—— 注意！metal 用 bar，real 用 atm
                                # pe/ke/etotal：能量（eV）—— 注意！metal 用 eV，real 用 kcal/mol

# ---- 速度初始化 ----
velocity all create 119.8 12345 dist gaussian
                                # 与 real 相同：温度单位都是 K

# ---- 轨迹输出 ----
dump mydump all atom 100 dump_metal.lammpstrj

# ---- 时间积分器 ----
fix 1 all nve

# ---- 时间步长 ----
timestep 0.01                   # 0.01 ps = 10 fs（与 real 中的 10.0 fs 物理上完全相同！）
                                # metal 单位下 timestep 的单位是 ps

# ---- 运行模拟 ----
run 1000                        # 1000 × 0.01 ps = 10 ps
```

**metal 与 real 的差异对照**（两者长度和质量单位相同，差异在能量和时间）：

| 参数 | Real 脚本 | Metal 脚本 | 转换关系 |
|------|-----------|-----------|---------|
| `ε` (pair_coeff) | 0.2381 kcal/mol | 0.01032 eV | 0.2381 × 0.04336 = 0.01032 eV |
| `timestep` | 10.0 fs | 0.01 ps | 10 fs = 0.01 ps |
| `压力单位` | atm | bar | 1 atm ≈ 1.013 bar |
| `能量单位` | kcal/mol | eV | 1 kcal/mol ≈ 0.04336 eV |

## 单位制对比实验

### 预期结果

三个脚本描述的是**完全相同的物理系统**。运行后，终端输出的热力学量数值会完全不同（因为"尺子"不同），但描述的是同一个物理状态：

| 热力学量 | LJ 输出 | Real 输出 | Metal 输出 | 转换验证 |
|----------|---------|-----------|-----------|---------|
| 温度 | ≈ 1.0 | ≈ 119.8 K | ≈ 119.8 K | 1.0 × 119.8 = 119.8 K ✓ |
| 密度 | ≈ 0.8442 | ≈ 1.40 g/cm³ | ≈ 1.40 g/cm³ | 质量密度一致 ✓ |
| 势能/原子 | ≈ -5.5 | ≈ -1.31 kcal/mol | ≈ -0.0568 eV | -5.5 × 0.2381 ≈ -1.31 ✓ |
| 总能量守恒？ | ✓ | ✓ | ✓ | 三个都守恒（NVE 系综） |

### 可视化验证

三个脚本分别输出不同名称的轨迹文件：
- `dump.lammpstrj`（LJ 约化坐标）
- `dump_real.lammpstrj`（Å 坐标）
- `dump_metal.lammpstrj`（Å 坐标）

用 OVITO 打开这三个文件，会看到**完全相同的原子排列和运动模式**（因为使用了相同的随机种子和相同的物理初始条件）。唯一的区别是坐标数值不同。
