## 背景知识

### 什么是分子动力学？

#### 从日常经验开始

想象你面前有一杯水。水是由无数个水分子组成的，每个分子都在不停地运动——振动、旋转、碰撞。如果你有一台"超级显微镜"，能放大到分子尺度，你会看到一幅极其繁忙的画面：分子们像一群永不停歇的弹珠，不断地相互碰撞、反弹、再碰撞。

**分子动力学（Molecular Dynamics，简称 MD）** 就是用计算机来模拟这种微观世界的运动。它做的事情本质上非常简单：

> 给定一堆"粒子"（原子或分子），按照物理定律计算它们之间的作用力，然后更新它们的位置和速度，如此循环往复。

#### 一个比喻：弹珠台

把分子动力学想象成一个三维弹珠台：

- **弹珠** = 原子。每个弹珠有自己的位置和速度。
- **弹簧** = 原子间的相互作用力。弹珠靠近时会互相推（排斥），保持一定距离时会轻轻拉（吸引）。
- **游戏规则** = 牛顿第二定律 $F = ma$。每个弹珠的运动方向和速度由它受到的合力决定。
- **时间推移** = 时间步长。每隔一小段时间（比如 0.005），我们重新计算所有弹珠的位置和速度。

模拟的过程就是：计算力 → 更新位置和速度 → 计算力 → 更新位置和速度 → ……如此重复成千上万次。最终，你得到了所有原子在一段时间内的运动轨迹。

#### 为什么要做模拟？

在真实实验中，我们很难直接"看到"原子在做什么。分子动力学模拟让我们能够在计算机中"重现"微观世界，从而：

- 观察原子如何运动和排列
- 预测物质的宏观性质（密度、压强、扩散系数等）
- 理解相变、结晶、扩散等微观机制
- 在做真实实验之前先筛选候选材料

#### "模拟"与"动画"的区别

请注意：MD 模拟不是"画"出来的动画。它是一个严格遵循物理定律的数值计算过程。每一帧都是由牛顿运动方程精确积分得到的。如果你改变参数（温度、密度、原子种类），结果会完全不同。这就像天气预报的计算——用物理方程一步步推演未来。

### LAMMPS 简介

#### 什么是 LAMMPS？

**LAMMPS**（Large-scale Atomic/Molecular Massively Parallel Simulator）是一款由美国桑迪亚国家实验室（Sandia National Laboratories）开发的开源分子动力学模拟软件。它是目前世界上使用最广泛的 MD 模拟软件之一。

#### LAMMPS 能做什么？

LAMMPS 可以模拟的体系非常广泛，包括但不限于：

- **软物质**：聚合物、胶体、生物分子（蛋白质、DNA）
- **金属与合金**：使用嵌入原子势（EAM）等描述金属键
- **陶瓷与矿物**：离子晶体、氧化物
- **粗粒化模型**：将多个原子"打包"成一个大粒子进行模拟
- **颗粒材料**：沙粒、粉末的流动

它支持从几千个原子到数十亿个原子的模拟，并且可以高效地在超级计算机上并行运行。

#### 为什么选择 LAMMPS 作为入门工具？

1. **开源免费**：任何人都可以下载和使用。
2. **文档完善**：官方文档非常详细，每个命令都有说明。
3. **社区活跃**：遇到问题很容易在网上找到解答。
4. **输入脚本简洁**：用纯文本命令控制，不需要写复杂程序。
5. **可扩展性强**：从简单模型到复杂研究都能胜任。

#### LAMMPS 的工作方式

LAMMPS 不是图形界面软件。它的使用方式是：

1. 你编写一个**输入脚本**（纯文本文件），告诉 LAMMPS 要做什么。
2. 在终端中运行命令 `lmp -in 你的脚本名`。
3. LAMMPS 读取脚本，执行模拟，并输出结果文件。

这就像写一个"剧本"，LAMMPS 是"演员"——你告诉它演什么，它就照着演。

### Lennard-Jones 势函数

#### 为什么需要"势函数"？

在分子动力学中，我们需要知道原子之间如何相互作用。这种相互作用用**势函数**（也叫力场）来描述。势函数本质上是一个数学公式，它告诉你：

> 当两个原子之间的距离为 $r$ 时，它们之间的相互作用能量 $E$ 是多少。

知道能量后，可以通过求导得到力：$F = -\frac{dE}{dr}$。有了力，就可以用牛顿第二定律 $F = ma$ 计算原子的加速度，从而更新速度和位置。

#### Lennard-Jones 势的公式

最经典的势函数之一是 **Lennard-Jones（LJ）势**，其数学形式为：

$$E(r) = 4\varepsilon \left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^{6}\right]$$

其中：
- $r$ 是两个原子之间的距离
- $\varepsilon$（epsilon）是**势阱深度**，表示相互作用的"强度"
- $\sigma$（sigma）是**零势距离**，大致代表原子的"直径"

#### 参数的物理含义

**$\varepsilon$（势阱深度）**：

想象两个原子之间的关系像一个山谷。$\varepsilon$ 就是这个山谷的深度。$\varepsilon$ 越大，原子之间的吸引力越强，需要更多能量才能把它们分开。在我们的模拟中设 $\varepsilon = 1$，这是一个参考值。如果换成真实物质（比如氩气），$\varepsilon$ 对应约 $1.65 \times 10^{-21}$ 焦耳。

**$\sigma$（零势距离）**：

$\sigma$ 是势能为零时两个原子之间的距离。你可以把它理解为原子的"有效直径"——当两个原子靠得比 $\sigma$ 更近时，它们会强烈排斥；比 $\sigma$ 更远时，开始相互吸引。在我们的模拟中设 $\sigma = 1$，同样是一个参考值。

#### 两项的物理意义

LJ 势由两项组成：

1. **排斥项** $\left(\frac{\sigma}{r}\right)^{12}$：当 $r < \sigma$ 时，这一项急剧增大，产生强烈的排斥力。这模拟了当两个原子靠得太近时，它们的电子云重叠产生的量子力学排斥效应（泡利排斥）。之所以取 12 次方，主要是为了计算方便（它是 6 次方的平方）。

2. **吸引项** $-\left(\frac{\sigma}{r}\right)^{6}$：当 $r > \sigma$ 时，这一项起主导作用，产生吸引力。这模拟了范德华力（London 色散力），来源于原子中电子的瞬时偶极。取 6 次方有严格的量子力学推导基础。

#### 势能曲线的形状

用文字描述 LJ 势能曲线的形状：

```
  能量 E
    |
    |  *                          （r → 0 时，E → +∞，强烈排斥）
    |   *
    |    *
    |     *
    |      *
    |       *
    |        *
    |         *
    |          *
    |           *
    |            *
    |             *
    |              *
  --+---*-----------*------------→ 距离 r
    |    σ          ↑
    |               势能最低点
    |               （平衡距离 r_min ≈ 1.12σ）
    |                    *
    |                        *
    |                            *
    |                                * → → 0（r → ∞，无相互作用）
    |
```

关键特征：
- **在 $r = \sigma$ 处**：势能 $E = 0$（零势点）
- **在 $r \approx 1.12\sigma$ 处**：势能达到最低值 $E = -\varepsilon$（势阱底部），这是两个原子的平衡距离
- **在 $r < \sigma$ 处**：势能急剧上升（排斥区）
- **在 $r > 1.12\sigma$ 处**：势能缓慢回升至零（吸引区）

#### 为什么用 LJ 势作为起点？

1. **简单**：只有两个参数（$\varepsilon$ 和 $\sigma$），容易理解和设置。
2. **经典**：几乎所有的 MD 教程都从 LJ 势开始。
3. **物理合理**：虽然简化了很多，但它抓住了原子间相互作用的核心特征——近处排斥、远处吸引。
4. **可解析**：很多热力学性质可以解析计算，方便验证模拟结果。
5. **适用范围广**：惰性气体（氩、氖、氪）的性质可以用 LJ 势很好地描述。

#### 截断距离

在实际模拟中，我们不会计算所有原子对之间的相互作用——当距离太远时，势能趋近于零，计算它们是浪费。因此，我们设置一个**截断距离** $r_c$，只计算 $r < r_c$ 的原子对。

在本项目中，$r_c = 2.5\sigma$。在 $r = 2.5\sigma$ 处，LJ 势能约为 $-0.0163\varepsilon$，已经非常小了。忽略更远的相互作用不会带来太大误差，但可以显著减少计算量。

### 输入脚本结构

LAMMPS 的输入脚本通常由以下几个部分组成，像一份"烹饪食谱"：

```
┌─────────────────────────────────┐
│  第一步：准备工作（初始化）      │  ← 选择单位制、原子样式
│  units, atom_style              │
├─────────────────────────────────┤
│  第二步：准备食材（体系定义）    │  ← 创建盒子、放置原子
│  region, create_box,            │
│  lattice, create_atoms          │
├─────────────────────────────────┤
│  第三步：调味料（力场设置）      │  ← 定义原子间相互作用
│  mass, pair_style,              │
│  pair_coeff                     │
├─────────────────────────────────┤
│  第四步：装锅（添加积分器）      │  ← 让原子真正"动起来"
│  fix nve                        │
├─────────────────────────────────┤
│  第五步：开火（设置参数+运行）   │  ← 设置速度、时间步长、运行
│  velocity, timestep, run        │
├─────────────────────────────────┤
│  第六步：装盘（输出结果）        │  ← 输出热力学和轨迹文件
│  thermo, dump,                  │
│  write_restart                  │
└─────────────────────────────────┘
```

记住这个结构，以后无论模拟多复杂，基本框架都是这几步。其中**第四步（fix nve）是最容易被遗忘的**——没有它，原子就不会运动！

## 输入脚本逐行解析

下面是 `in.melt` 脚本的逐行详细解析。

---

### 第一部分：初始化

```lammps
units           lj
```

> **设置单位制为 Lennard-Jones 约化单位。**
>
> 这是输入脚本的第一个命令，告诉 LAMMPS 使用什么单位来衡量物理量。在 `lj` 单位制下，四个基本物理量都归一化为 1：
>
> | 物理量 | 符号 | LJ 单位值 | 含义 |
> |--------|------|-----------|------|
> | 质量   | $m$  | 1         | 原子质量单位 |
> | 长度   | $\sigma$ | 1     | 原子直径 |
> | 能量   | $\varepsilon$ | 1 | 势阱深度 |
> | 玻尔兹曼常数 | $k_B$ | 1 | 温度-能量转换因子 |
>
> 这意味着所有物理量都是无量纲的。例如，温度 $T = 1.44$ 不是 1.44 开尔文，而是 1.44 个 LJ 温度单位（即 $k_BT/\varepsilon = 1.44$）。
>
> **注意**：`units` 命令必须出现在几乎所有其他命令之前。LAMMPS 不允许在脚本中间更改单位制。

```lammps
atom_style      atomic
```

> **设置原子样式为"atomic"。**
>
> 这告诉 LAMMPS 每个原子携带哪些信息。`atomic` 是最简单的样式——每个原子只有位置、速度和类型，没有电荷、没有键接关系。
>
> 其他常见的样式包括：
> - `charge`：带电荷的原子（用于离子体系）
> - `molecular`：有键接关系的分子（用于聚合物、蛋白质等）
> - `full`：包含电荷和键接（最完整）
>
> **注意**：`atom_style` 必须在创建模拟盒子之前设置。如果在创建盒子之后更改，会出错。

---

### 第二部分：体系定义

```lammps
region          mybox block 0 10 0 10 0 10
```

> **定义一个名为 `mybox` 的长方体区域。**
>
> 参数格式：`block xlo xhi ylo yhi zlo zhi`
> - `0 10`：X 方向从 0 到 10（LJ 长度单位，即 10σ）
> - `0 10`：Y 方向从 0 到 10
> - `0 10`：Z 方向从 0 到 10
>
> 这定义了一个 $10\sigma \times 10\sigma \times 10\sigma$ 的立方体空间。`region` 命令本身不创建任何东西，只是画了一个"范围"——后续的 `create_box` 和 `create_atoms` 命令会用到它。
>
> **注意**：区域名称 `mybox` 是自定义的，你可以改成任何名字。

```lammps
create_box      1 mybox
```

> **在 `mybox` 区域内创建模拟盒子，包含 1 种原子类型。**
>
> 这个命令做了几件事：
> 1. 根据 `mybox` 区域的大小初始化模拟盒子（3D 周期性盒子）
> 2. 宣布盒子里将有 1 种原子类型
> 3. 为后续的原子创建分配内存
>
> 参数 `1` 表示只有 1 种原子类型。如果你要模拟两种不同的原子（比如铜和金），就改成 `2`。
>
> **常见错误**：必须先定义 `region`，才能用 `create_box` 引用它。顺序不能反。

```lammps
lattice         fcc 0.8442
```

> **设置晶格类型为面心立方（FCC），约化密度为 0.8442。**
>
> - `fcc`：面心立方晶格（Face-Centered Cubic），是一种常见的晶体结构。每个晶胞有 4 个原子，位于立方体的 8 个顶点和 6 个面的中心。
> - `0.8442`：这是**约化密度** $\rho^*$，定义为 $\rho^* = N\sigma^3/V$，其中 $N$ 是原子数，$V$ 是体积。
>
> 0.8442 是 LJ 体系中一个非常经典的密度值——它对应 LJ 相图中液态区域的一个参考点。选择这个值的原因是：
> - 它在很多文献中被使用，方便对比结果
> - 它产生的液体结构具有良好的统计性质
> - 原子既不会太稀（像气体）也不会太挤（产生重叠）
>
> **注意**：`lattice` 命令本身不创建原子，只是定义了"模板"。后续的 `create_atoms` 命令才真正放置原子。

```lammps
create_atoms    1 box
```

> **在模拟盒子中按晶格模板创建原子。**
>
> - `1`：创建的原子类型为 1（对应之前定义的唯一原子类型）
> - `box`：在整个盒子范围内创建原子
>
> LAMMPS 会根据 `lattice` 命令设置的晶格类型和密度，在盒子中规则地排列原子。对于 $10 \times 10 \times 10$ 的盒子和 FCC 晶格（$\rho^* = 0.8442$），晶格间距约为 $1.68\sigma$，因此每条边放置 6 个晶胞，共 $6 \times 6 \times 6 = 216$ 个晶胞，每个 FCC 晶胞有 4 个原子，总计 $216 \times 4 = 864$ 个原子。
>
> 你也可以只在部分区域创建原子，比如 `create_atoms 1 region mysubregion`。

---

### 第三部分：力场设置

```lammps
mass            1 1.0
```

> **设置原子类型 1 的质量为 1.0。**
>
> 在 LJ 单位制中，质量单位就是 $m$，所以 `1.0` 意味着质量为 1 个 LJ 质量单位。由于我们只有一种原子类型，只需设置一次。
>
> 质量会影响原子的运动惯性——质量越大，在相同力作用下加速度越小（$a = F/m$）。它还会影响动能的计算：$E_k = \frac{1}{2}mv^2$。

```lammps
pair_style      lj/cut 2.5
```

> **设置对势类型为 Lennard-Jones 势，截断半径为 2.5。**
>
> - `lj/cut`：表示使用标准 LJ 势，并在截断距离处直接"切掉"（不做任何修正）。还有其他变体如 `lj/smooth`（平滑截断）、`lj/long`（长程修正）等。
> - `2.5`：截断半径 $r_c = 2.5\sigma$。当两个原子距离大于 2.5 时，不计算它们之间的相互作用。
>
> 为什么选 2.5？
> - 在 $r = 2.5\sigma$ 处，LJ 势能约为 $-0.016\varepsilon$，已经很小
> - 这是 MD 模拟中公认的"标准"截断距离
> - 太小的截断会丢失重要物理信息；太大会增加计算量
>
> **注意**：截断半径的选择会影响能量守恒和物理性质的精度。改变截断半径后，结果可能会有变化（见练习题 3）。

```lammps
pair_coeff      1 1 1.0 1.0
```

> **设置原子类型 1 与类型 1 之间的 LJ 势参数。**
>
> 参数格式：`pair_coeff i j ε σ`
> - `1 1`：这是类型 1 与类型 1 之间的相互作用（同种原子）
> - `1.0`：$\varepsilon = 1.0$（势阱深度，1 个能量单位）
> - `1.0`：$\sigma = 1.0$（原子直径，1 个长度单位）
>
> 截断半径沿用 `pair_style lj/cut 2.5` 中设定的 $r_c = 2.5\sigma$。你也可以在这里指定不同的截断半径，例如 `pair_coeff 1 1 1.0 1.0 3.0` 会让这一对原子使用 3.0 的截断。
>
> 对于只有一种原子类型的体系，只需要定义一对 `pair_coeff`。如果有多种原子类型（比如类型 1 和类型 2），还需要定义 `pair_coeff 1 2 ...`。
>
> **常见错误**：如果忘记设置 `pair_coeff`，LAMMPS 会报错说找不到对应类型对的参数。另外，如果在 `pair_coeff` 中指定了过小的截断半径（如 `pair_coeff 1 1 1.0 1.0 1.0`），会导致原子间相互作用范围太短，产生严重的能量漂移。

### 第四部分：初始条件

```lammps
velocity        all create 1.44 87287 loop geom
```

> **为所有原子创建初始速度，目标温度为 1.44。**
>
> - `all`：作用对象为所有原子
> - `create`：从零开始创建速度（区别于 `set` 命令修改已有速度）
> - `1.44`：目标温度 $T^* = 1.44$（LJ 约化温度）
> - `87287`：随机数种子。改变这个数字会得到不同的初始速度分布，但最终的平衡态性质应该相同（遍历性）
> - `loop geom`：使用几何循环方式确保总动量为零（系统没有整体漂移）
>
> 温度与原子动能的关系为：
> $$\frac{3}{2}Nk_BT = \sum_{i=1}^{N}\frac{1}{2}mv_i^2$$
>
> 其中 $N$ 是原子数，$v_i$ 是第 $i$ 个原子的速度。
>
> $T^* = 1.44$ 在 LJ 相图中高于临界温度（$T_c^* \approx 1.3$），因此系统处于超临界流体状态——既不是液体也不是气体，而是一种高密度的流体。
>
> **注意**：初始速度是随机分配的。这意味着模拟刚开始时系统可能还没有"热化"，温度会有短暂的波动。通常在前几百步内温度就会稳定下来。

### 第六部分：运行

```lammps
fix             1 all nve
```

> **添加 NVE 积分器——这是让原子真正"动起来"的关键命令！**
>
> - `fix`：LAMMPS 中的"修复"命令，用于在每个时间步执行特定操作（如积分、控温等）
> - `1`：这个 fix 的编号（可以是任意正整数，但不能与其他 fix 重复）
> - `all`：作用于所有原子
> - `nve`：使用 Velocity-Verlet 积分算法，在 NVE 系综下运动
>
> **为什么需要这行？**
>
> 没有 `fix nve`（或其他积分器），LAMMPS 只会计算力但不会更新原子的位置和速度。原子会永远"冻结"在初始位置。这就是为什么这行命令至关重要——它告诉 LAMMPS："根据你算出来的力，按照牛顿第二定律 $F = ma$，去更新每个原子的速度和位置。"
>
> Velocity-Verlet 算法的基本步骤是：
> 1. 用当前位置计算力 $F(t)$
> 2. 更新位置：$r(t+\Delta t) = r(t) + v(t)\Delta t + \frac{1}{2}\frac{F(t)}{m}\Delta t^2$
> 3. 用新位置计算力 $F(t+\Delta t)$
> 4. 更新速度：$v(t+\Delta t) = v(t) + \frac{F(t) + F(t+\Delta t)}{2m}\Delta t$
>
> 这个算法具有二阶精度，能很好地保持能量守恒。
>
> **常见错误**：新手最容易犯的错误之一就是忘记添加 `fix nve`。如果你运行脚本后发现所有物理量（温度、能量、压强）都不变，首先检查是否缺少这行命令。
>
> **NVE vs NVT vs NPT**：
> - `fix nve`：不控温不控压，能量近似守恒（微正则系综）
> - `fix nvt`：控温（正则系综），后续项目 04 会介绍
> - `fix npt`：控温又控压（等温等压系综），后续项目 05 会介绍

```lammps
timestep        0.005
```

> **设置时间步长为 0.005 个 LJ 时间单位。**
>
> 时间步长 $\Delta t$ 是每次积分推进的时间长度。每个时间步中，LAMMPS 会：
> 1. 计算所有原子受的力
> 2. 根据 $F = ma$ 更新速度
> 3. 根据速度更新位置
>
> LJ 时间单位 $\tau = \sigma\sqrt{m/\varepsilon}$。当 $m = \sigma = \varepsilon = 1$ 时，$\tau = 1$。所以 $\Delta t = 0.005\tau$。
>
> 为什么选 0.005？
> - 太大（如 0.05）：原子可能在一步内"跳"得太远，导致能量不守恒甚至原子重叠
> - 太小（如 0.0001）：精度很高但计算太慢，浪费时间
> - 0.005 是 LJ 液体模拟中的经典选择，精度和效率之间取得了良好平衡
>
> **经验法则**：时间步长应该远小于原子振动的特征时间。对于 LJ 体系，特征时间约为 $\tau$，所以 $\Delta t \approx 0.005\tau$ 是合理的。

```lammps
run             10000
```

> **运行 10000 个时间步。**
>
> 总模拟时间 = $10000 \times 0.005 = 50\tau$。
>
> 这是整个脚本的"核心"——一切准备工作都是为了这一行。运行期间，LAMMPS 会：
> 1. 循环执行力计算和积分
> 2. 按设定频率输出热力学和轨迹
> 3. 在终端显示进度
>
> 10000 步对于学习来说足够了，但对于正式研究通常需要更多步数以达到平衡并采集统计数据。

在 NVE 系综（微正则系综，即粒子数 N、体积 V、能量 E 守恒）中，总能量应该保持近似恒定。如果总能量波动较大（比如变化超过 1%），说明时间步长可能太大了。良好的能量守恒是模拟质量的重要保证。

## 关键概念总结

### 系综（Ensemble）

**系综**是统计力学中的一个基本概念，指的是对模拟条件的约束方式。最常见的三种系综是：

| 系综 | 英文 | 守恒量 | 含义 |
|------|------|--------|------|
| NVE | 微正则系综 | 粒子数 N、体积 V、能量 E | 系统完全孤立，能量守恒 |
| NVT | 正则系综 | N、V、温度 T | 系统与热浴接触，温度恒定 |
| NPT | 等温等压系综 | N、压强 P、温度 T | 温度和压强都恒定 |

本项目的模拟是 **NVE 系综**——我们没有使用任何控温器或控压器，系统完全靠初始条件演化。后续项目（04 和 05）会介绍如何使用恒温器和恒压器。

> **通俗理解**：系综就像你对房间的控制方式。NVE 是"把房间完全密封"（没有空调、没有窗户）；NVT 是"开空调保持恒温"；NPT 是"既开空调又控制气压"。

### 时间步长（Timestep）

**时间步长** $\Delta t$ 是分子动力学中最关键的参数之一。它决定了模拟的精度和效率：

- **太大的 $\Delta t$**：原子可能在一步内"跨越"得太远，导致：
  - 能量不守恒（数值积分误差累积）
  - 原子发生非物理的重叠
  - 模拟崩溃（原子"飞出"盒子）

- **太小的 $\Delta t$**：精度很高，但计算量大幅增加。模拟同样的物理时间需要更多的步数。

**选择时间步长的经验法则**：

> 时间步长应该比体系中最快的振动周期小约 1/20 到 1/10。

对于 LJ 体系，原子振动的特征时间约为 $\tau = \sigma\sqrt{m/\varepsilon}$，所以 $\Delta t \approx 0.005\tau$ 是合理的选择。

| 体系类型 | 典型时间步长 |
|----------|-------------|
| LJ 液体/气体 | 0.001 ~ 0.005 $\tau$ |
| 金属（EAM 势） | 1 ~ 2 飞秒（fs） |
| 水（刚性分子） | 1 ~ 2 飞秒 |
| 生物分子（有氢键） | 1 ~ 2 飞秒 |
| 粗粒化模型 | 5 ~ 20 飞秒 |

### 周期性边界条件（Periodic Boundary Conditions，PBC）

#### 为什么需要 PBC？

我们模拟的是少量原子（几千到几百万个），但真实材料包含约 $10^{23}$ 个原子。如何用少量原子模拟"无限大"的体系？

答案就是**周期性边界条件**：把模拟盒子在三个方向上无限复制，形成一个"无限大"的周期性体系。

#### PBC 如何工作？

想象一个正方形盒子中的原子。当一个原子从盒子的**右边**飞出时，PBC 会让一个"虚拟的"该原子同时从**左边**飞入。这就像一个环形世界——从东边走到尽头，就出现在西边。

```
     +----------+    +----------+    +----------+
     |          |    |          |    |          |
     |    *→    |    |    *→    |    |    *→    |
     |          |    |          |    |          |
     +----------+    +----------+    +----------+
         复制盒子        原始盒子         复制盒子
```

#### PBC 的效果

- **消除表面效应**：所有原子都"感觉"自己处于体相内部，不会因为靠近边界而受到异常影响
- **模拟"无限大"体系**：用有限数量的原子模拟宏观材料
- **保持守恒**：系统中没有原子"消失"或"凭空出现"

#### PBC 的注意事项

- **盒子不能太小**：如果盒子太小，原子可能会"看到"自己的周期镜像，产生非物理的自相互作用。一般要求盒子边长至少为截断半径的 2 倍（即 $L > 2r_c$）。
- **不是所有模拟都用 PBC**：纳米颗粒、蛋白质在溶液中的模拟有时使用非周期性边界（如 `boundary f f f`）。

## 练习题

以下练习帮助你加深对本项目内容的理解。建议每次只修改一个参数，观察变化。

### 练习 1：改变初始温度

**任务**：分别将初始温度改为 0.5 和 3.0，运行模拟并比较结果。

**如何修改**：将 `velocity` 命令中的温度参数从 1.44 改为 0.5 或 3.0：
```lammps

```

**预期观察**：
- **T = 0.5**（低温）：原子运动缓慢，系统可能形成有序结构（结晶倾向）。温度较低时，原子没有足够的动能克服势阱，倾向于停留在平衡位置附近。
- **T = 3.0**（高温）：原子运动剧烈，系统呈现高度无序的气态或超临界流体状态。势能项相对不那么重要，动能占主导。

### 练习 2：改变原子密度

**任务**：分别将晶格密度改为 0.2 和 1.2，运行模拟并观察结果。

**如何修改**：将 `lattice` 命令中的密度参数从 0.8442 改为 0.2 或 1.2：
```lammps
lattice   fcc 0.2
```

**预期观察**：
- **密度 0.2**（低密度）：原子非常稀疏，大部分原子处于孤立状态，类似气态。系统压强很低，原子间相互作用很少。
- **密度 1.2**（高密度）：原子非常密集，初始配置中很多原子可能重叠或距离很近。这会导致巨大的排斥力，模拟可能在前几步出现剧烈的能量脉冲。如果模拟"爆炸"（原子飞出盒子），说明密度太大了——这也是一种有价值的学习体验！

### 练习 3：改变截断半径

**任务**：将 `pair_style` 的截断半径从 2.5 改为 1.12，观察能量变化。

**如何修改**：
```lammps

```

**预期观察**：
- 截断半径 1.12 恰好对应 LJ 势能的最低点（$r_{min} = 2^{1/6}\sigma \approx 1.12\sigma$）。这意味着只保留了排斥部分，几乎丢掉了全部吸引力！
- 系统会表现得像硬球气体——原子之间只有排斥，没有吸引
- 势能会明显偏正（排斥），系统压强会升高
- 总能量的值和平衡态性质都会显著不同
- 这个练习帮助你理解**为什么截断半径的选择很重要**

### 练习 4：增加运行步数

**任务**：将运行步数从 10000 增加到 50000，观察系统是否达到平衡。

**如何修改**：
```lammps
run       50000
```

**预期观察**：
- 更长的模拟时间意味着系统有更多时间趋于平衡
- 观察温度和能量：如果在 10000 步之后它们仍在缓慢变化，说明系统可能还没有完全平衡
- 观察压强的波动：平衡后压强的平均值应该趋于稳定
- 轨迹文件会更大，包含 500 帧而不是 100 帧
